# GUI 图片来源统一说明（2026-06-20）

## 背景

从用户视角看，图片素材来源应当是同一个选择：

- `local`：使用本地 `assets` 文件。
- `aliyun`：使用阿里云百炼 / DashScope AI 生图。
- `pexels`：使用 Pexels 搜图下载。

此前 GUI 把本地 `assets glob` 和 `配图来源` 分成两个区域，容易造成误解：用户选择了 `aliyun`，但如果 `assets/pics/*` 里已有图片，后端会优先上传本地图片，而不会触发 AI 生图。

## 修复

- 自动发帖页把“配图来源”改为“图片来源”，下拉项统一为 `local` / `aliyun` / `pexels`。
- 选择 `local` 时：
  - 启用 `本地 assets glob` 输入框。
  - GUI 注入 `AUTO_IMAGE=0`，避免意外调用 AI/Pexels。
- 选择 `aliyun` 或 `pexels` 时：
  - 禁用本地 assets 输入框。
  - CLI 参数自动使用 `--assets-glob assets/empty/*`，确保后端进入自动配图分支。
  - GUI 注入 `AUTO_IMAGE=1` 和对应 `IMAGE_PROVIDER`。
- 选择 `aliyun` 时，阿里云生图模型选择框可用；选择 `local` 或 `pexels` 时该模型框禁用。

## 对应关系

| GUI 图片来源 | CLI assets 参数 | 环境变量 | 实际行为 |
|---|---|---|---|
| `local` | 用户填写的本地 glob，例如 `assets/pics/*` | `AUTO_IMAGE=0` | 使用本地图片，不自动补图 |
| `aliyun` | `assets/empty/*` | `AUTO_IMAGE=1`, `IMAGE_PROVIDER=aliyun` | 无本地图片，触发阿里云 AI 生图 |
| `pexels` | `assets/empty/*` | `AUTO_IMAGE=1`, `IMAGE_PROVIDER=pexels` | 无本地图片，触发 Pexels 搜图 |

## 验证

- `python -m py_compile apps/gui.py` 通过。
- `pytest tests/test_gui.py -q` 通过。
- 新增测试覆盖：
  - GUI 暴露三种图片来源。
  - `aliyun` / `pexels` 来源会忽略本地 assets glob 并切到 `assets/empty/*`。
  - `local` 来源会关闭自动配图。
