# 每日新闻人工材料双模式（2026-07-05）

## 背景

人工新闻材料入口需要拆成两个明确模式：

1. 单条新闻材料文件：用户只提供一条完整新闻文本，软件只生成一条 `每日新闻`，不再需要提示词、数量、回溯天数参与筛选。
2. 多条新闻材料文件：用户提供长文件，文件内包含多条新闻，软件把它作为候选池，继续使用提示词、数量、回溯天数做筛选。

## CLI 入口

### 单条新闻材料

```powershell
.\.venv\Scripts\python.exe -m apps.cli auto `
  --title 每日新闻 `
  --single-news-material-file data\manual_news\one.md `
  --assets-glob assets\empty\* `
  --login-hold 600 `
  --wait-timeout 600
```

规则：

- `--single-news-material-file` 文件内必须只能解析出一条新闻。
- 该模式固定生成 1 条草稿。
- 即使命令里传入 `--prompt`、`--count`、`--lookback-days`，每日新闻链路也会忽略这些筛选参数。
- 该模式与 `--news-materials-file` 互斥。

### 多条新闻材料

```powershell
.\.venv\Scripts\python.exe -m apps.cli auto `
  --title 每日新闻 `
  --prompt "财经产业 / 公司政策 / 市场变化" `
  --news-materials-file data\manual_news\many.md `
  --count 3 `
  --lookback-days 7 `
  --assets-glob assets\empty\* `
  --login-hold 600 `
  --wait-timeout 600
```

规则：

- `--news-materials-file` 仍作为多条候选池入口。
- 提示词继续用于材料池内相关性筛选。
- 数量继续控制最终生成草稿数。
- 回溯天数继续过滤材料中的发布时间。

## GUI 入口

`自动发帖` 页面现在拆成两个文件输入：

- `单条新闻材料文件`：单条新闻文本，固定生成 1 条，不使用提示词、数量、回溯筛选。
- `多条新闻材料文件`：长文件候选池，保留提示词、数量、回溯筛选。

GUI 命令构造规则：

- 单条文件不为空时，生成命令包含 `--single-news-material-file` 和 `--count 1`。
- 单条文件不为空时，不生成 `--prompt`、`--lookback-days`。
- 多条文件不为空时，生成命令包含 `--news-materials-file`，并保留提示词、数量、回溯天数。
- 两个文件字段同时填写时，GUI 会报错，不构造命令。

## 配图策略

单条新闻材料模式使用 AI 生图优先策略：

- 无本地素材且 `AUTO_IMAGE` 未关闭时，系统先调用 AI 生图供应商。
- AI 生图供应商优先级：
  1. `SINGLE_NEWS_AI_IMAGE_PROVIDER`
  2. `DAILY_NEWS_AI_IMAGE_PROVIDER`
  3. `IMAGE_PROVIDER`，仅当其为 `aliyun` / `volcengine` 等 AI 生图供应商时使用
  4. 默认 `aliyun`
- 如果 AI 生图失败，包括超时、额度、接口或配置错误，系统再回退到 `pexels` 搜图配图。
- 回退信息会写入 `post.platform.image_fallback`，包含 `from_provider`、`to_provider`、错误类型和错误摘要。

多条新闻材料模式仍沿用当前图片来源设置，不强制 AI-first。

## 材料格式

两种模式都复用现有 `.md/.txt/.json/.jsonl` 解析能力，支持字段：

- 标题：`标题`、`新闻`、`新闻标题`、`title`、`headline`
- 时间：`时间`、`发布时间`、`发布日期`、`日期`、`published_at`、`seendate`
- 来源：`来源`、`媒体`、`source`、`source_name`
- 链接：`链接`、`原文链接`、`网址`、`url`、`link`
- 摘要：`摘要`、`简介`、`导语`、`summary`、`description`
- 正文：`内容`、`正文`、`新闻内容`、`原文`、`content`、`body`
- 热度：`热度`、`关注度`、`阅读`、`浏览`、`views`、`score`

单条模式示例：

```markdown
标题：央行发布支付便利化新举措
时间：2026-07-05 09:30
来源：中国新闻网
链接：https://example.cn/payments
内容：央行表示将优化重点场景支付服务，提升境内外人员支付便利性。
```
