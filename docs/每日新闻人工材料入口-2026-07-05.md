# 每日新闻人工材料入口（2026-07-05）

## 背景

用户希望不再由程序在线搜索新闻，而是把已整理好的新闻材料直接提供给软件。材料中包含新闻标题、时间、来源、正文、链接、热度等信息，软件仍负责从这些材料中筛选新闻、生成 `每日新闻` 标题、正文、评价和配图。

本次新增 `manual` 新闻来源，用于把“获取新闻”这一步替换成“读取用户提供的材料文件”。

## 使用方式

### CLI

`auto` 和 `create` 都支持：

```powershell
.\.venv\Scripts\python.exe -m apps.cli auto `
  --title 每日新闻 `
  --prompt "财经产业 / 公司政策 / 市场变化" `
  --news-materials-file data\manual_news\today.md `
  --assets-glob assets\empty\* `
  --count 3 `
  --login-hold 600 `
  --wait-timeout 600
```

也可以使用环境变量：

```powershell
$env:NEWS_MATERIALS_FILE="data\manual_news\today.md"
.\.venv\Scripts\python.exe -m apps.cli auto --title 每日新闻 --count 3
```

只要提供 `--news-materials-file` 或 `NEWS_MATERIALS_FILE`，本次任务会优先使用人工材料，不再在线抓取新闻。

### GUI

“自动发帖”页新增 `新闻材料文件` 输入框和 `浏览` 按钮。

- 留空：沿用原来的在线新闻源。
- 填写文件路径：只从该文件读取每日新闻候选。
- 该入口仅影响 `每日新闻`；`每日AI讯息` 仍走自身采集链路。

GUI 自动运行可用：

```powershell
$env:AUTO_REDBOOK_GUI_NEWS_MATERIALS_FILE="data\manual_news\today.md"
```

## 材料格式

支持 `.md`、`.txt`、`.json`、`.jsonl`。

### Markdown / TXT

多条新闻用 `---` 分隔。字段名支持中英文，常用字段如下：

```markdown
标题：央行发布支付便利化新举措
时间：2026-07-05 09:30
来源：中国新闻网
链接：https://example.cn/payments
热度：8765
内容：央行表示将优化重点场景支付服务，提升境内外人员支付便利性。

---

新闻：国际足联公布世界杯票务安排
发布时间：2026-07-04
来源：新华社
url: https://example.cn/worldcup
摘要：世界杯相关票务安排发布，多个阶段将分批开放申请。
正文：赛事组织方提醒球迷关注官方渠道。
```

### JSON

```json
{
  "news": [
    {
      "新闻": "国内算力项目落地西部园区",
      "时间": "2026-07-05",
      "来源": "证券时报",
      "链接": "https://example.cn/compute",
      "正文": "项目将服务AI训练和产业数字化场景。"
    }
  ]
}
```

也兼容 `items`、`candidates` 字段。

### JSONL

```jsonl
{"标题":"暑期文旅市场热度上升","时间":"2026-07-05","来源":"央视新闻"}
{"标题":"体育赛事带动周边消费","时间":"2026-07-05","来源":"人民网"}
```

## 字段映射

- 标题：`标题`、`新闻`、`新闻标题`、`title`、`headline`
- 时间：`时间`、`发布时间`、`发布日期`、`日期`、`published_at`、`seendate`
- 来源：`来源`、`媒体`、`source`、`source_name`
- 链接：`链接`、`原文链接`、`网址`、`url`、`link`
- 摘要：`摘要`、`简介`、`导语`、`summary`、`description`
- 正文：`内容`、`正文`、`新闻内容`、`原文`、`content`、`body`
- 热度：`热度`、`关注度`、`阅读`、`浏览`、`views`、`score`

如果缺少链接，系统会生成本地追踪用的 `manual://news/...` 链接，并把来源域名记为 `manual.local`。建议仍提供原文链接，方便追溯。

## 筛选规则

人工材料进入同一套 `每日新闻` 候选池逻辑：

- 仍按 `--lookback-days` 或默认 `3 -> 7 -> 14` 北京时间窗口过滤。
- 仍按提示词相关度筛选。
- 仍按热度、发布时间、来源多样性排序。
- 仍经过单故事聚焦、正文规范化、简体中文和质量闸门。

因此，如果材料中的时间超过回溯窗口，或者没有任何材料匹配提示词，仍会报 `daily news material insufficient`。
