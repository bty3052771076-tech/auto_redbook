# 每日新闻与每日AI讯息回溯窗口（2026-07-04）

## 背景

用户需要在生成“每日新闻”和“每日AI讯息”时，可以选择“发帖日 N 天内”的素材进入筛选池。同时，默认行为不能再因为三日素材不足就直接失败，也不能无限放宽到上个月旧新闻。

本次规则：

- GUI 增加“回溯天数”输入框。
- CLI 增加 `--lookback-days` 参数。
- 留空时自动按 `3 -> 7 -> 14` 天逐级尝试。
- 填写数字时固定只使用发帖日 N 天内素材，不自动扩展。
- 14 天内仍不足时停止生成，并说明新闻或 AI 讯息素材不足。

## 行为规则

### 留空：自动扩展

默认窗口为北京时间自然日窗口：

1. 先筛选发帖日当天、昨天、前天，即 3 天内素材。
2. 如果不足，再扩展到 7 天内。
3. 如果仍不足，再扩展到 14 天内。
4. 如果 14 天内仍不足，请求失败，并在终端/GUI 日志中输出 `material insufficient` 和每个窗口的候选数量。

### 填写数字：固定窗口

例如：

```powershell
.\.venv\Scripts\python.exe -m apps.cli auto --title "每日新闻" --prompt "世界杯 体育 足球" --count 3 --lookback-days 7
```

此时只使用发帖日 7 天内素材。如果 7 天内不足，不会再扩到 14 天。

## 每日新闻实现

入口：`src/workflow/create_post.py` 的 `_fetch_daily_news_candidates_for_upload(...)`。

- 原始抓取数量仍按生成数量多抓，当前为 `count * 20` 的下限。
- 留空时一次按最大 14 天获取原始候选，然后依次用 3、7、14 天窗口过滤。
- 每个窗口内继续执行提示词相关度、热度、时效性和来源多样性排序。
- metadata 的 `selection_pool.lookback` 会记录：
  - `mode`: `auto_expand` 或 `fixed`
  - `windows`: 尝试过的窗口
  - `selected_max_age_days`: 最终使用的窗口
  - `attempts`: 每个窗口的候选数量

## 每日AI讯息实现

入口：`src/workflow/create_post.py` 的 `create_daily_ai_digest_posts(...)`。

- 留空时先按最大 14 天窗口采集一次，再在本地依次筛选 3、7、14 天窗口，避免每个窗口重复请求所有官方源和补充源。
- 每个窗口仍保留最少 8 条、至少 3 条国内模型资讯、至少 3 条国外 AI 资讯的要求。
- AI HOT 与新闻源补充会跟随当前窗口天数。
- metadata 的 `platform.ai_digest.source_meta.lookback` 会记录窗口尝试过程。

## GUI

“自动发帖”页新增：

```text
回溯天数 [      ]
```

- 留空：自动使用 `3 -> 7 -> 14`。
- 填写 `7`：固定只筛 7 天内素材。
- 自动运行环境变量：`AUTO_REDBOOK_GUI_LOOKBACK_DAYS`。

## CLI 与环境变量

推荐使用 CLI 参数：

```powershell
--lookback-days 7
```

兼容环境变量：

- 通用：`CONTENT_LOOKBACK_DAYS`
- 每日新闻：`NEWS_LOOKBACK_DAYS`
- 每日AI讯息：`AI_DIGEST_LOOKBACK_DAYS`
- 旧变量：`AI_DIGEST_MAX_AGE_DAYS` 仍兼容为每日AI讯息固定窗口。
