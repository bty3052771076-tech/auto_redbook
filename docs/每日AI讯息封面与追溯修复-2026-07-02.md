# 每日AI讯息封面与追溯修复（2026-07-02）

## 背景

`每日AI讯息` 之前仍有几个明显问题：

- 封面顶部固定显示 `Auto Redbook AI Brief`，中部固定显示 `本期整理 10 条动态`，信息密度低。
- 每页底部显示 `来源链接已保存至本地 metadata` 或 `长链接不写入图片，完整来源保存在本地`，影响成图观感。
- 当 LLM 不可用或 LLM 返回过泛时，标题/摘要会变成 `xxx发布AI动态`，缺少真正的信息量。
- 内容页没有逐条显示发布时间；部分 HTML 发布页解析时也会丢失发布日期，导致 metadata 不完整。

## 根因

### 1. 渲染层固定文案

`src/ai_digest/render.py` 的 `_render_cover()` 和 `_render_items_page()` 直接写死了英文封面文案、数量胶囊和底部提示。因此即使数据内容已经足够，图片仍会出现旧模板文字。

### 2. 兜底中文化过于保守

`src/ai_digest/generate.py` 的 `_fallback_chinese_title()` 对非中文标题只根据厂商/产品拼出：

```text
<厂商或产品>发布AI动态
```

这能保证中文，但会损失原始标题里的模型名、工具名和功能变化。

### 3. HTML 发布页缺少日期上下文

`src/ai_digest/fetchers.py` 之前只看单行文本。如果发布页结构是：

```text
2026年7月2日
GLM-5.2 模型发布...
```

解析更新行时不会继承上一行日期。

## 修复

### 封面

- 移除 `Auto Redbook AI Brief`。
- 移除 `本期整理 N 条动态` 胶囊。
- 新增 `今日重点` 深色卡片，展示本期热度最高的一条 AI 动态。
- 热度选择规则基于 `confidence_score`、证据链接数量、来源类型优先级和发布时间。

### 内容页

- 移除所有底部来源提示。
- 每条 AI 动态卡片底部显示：

```text
发布时间：YYYY-MM-DD HH:MM  来源：来源名称  官方源/社交补充/官方源 + 社交验证
```

### 内容质量

- LLM 结果或本地兜底中若出现 `发布AI动态`、`具体链接已保存在本地元数据` 等泛化句，会从原始候选的 `title / summary / raw_excerpt` 恢复更具体的标题和摘要。
- 英文候选会尽量保留模型/产品名，例如 `GPT-5.2 Codex CLI`、`Claude Code`，并把常见能力词翻成自然中文，例如 `browser automation -> 浏览器自动化`、`background agents -> 后台智能体`。
- LLM 若遗漏 `url`、`published_at`、`source_name` 等追溯字段，会按 URL、厂商、产品和顺序从原始候选恢复。

### 发布时间

- RSS / GitHub Releases 使用源自带发布时间。
- 普通 HTML 发布页会提取同一行日期，也会把最近的日期标题继承给后续发布行。
- 若源没有给出精确发布时间，最终 brief 会填入本期日期，避免图片和 metadata 出现空白时间；完整来源 URL 仍保存在 metadata 中供复核。

## 阿里云 GLM5.2 本地验证

本次使用进程级环境变量临时指定阿里云 GLM5.2，没有写入 `.env`、`.env.gui` 或 key 文件：

```powershell
$env:LLM_PROVIDER="aliyun"
$env:ALIYUN_LLM_MODEL="glm-5.2"
$env:ALIYUN_LLM_MODELS="glm-5.2"
$env:AI_DIGEST_TARGET_ITEMS="10"
$env:AI_DIGEST_MIN_OFFICIAL_ITEMS="6"
$env:AI_DIGEST_PRIMARY_SOURCES="openai,anthropic,deepmind,huggingface,github-ai,zhipu-glm,aliyun"
```

验证结果：

- 本地生成 post：`data/posts/a32e1f57802c4fceb327ff295e177144/post.json`
- `generation_mode=llm`
- LLM：`provider=aliyun`，`model=glm-5.2`
- 图片：5 张，本地模板渲染，包含 1 张封面 + 4 张内容页
- 条目：10 条
- `bad_generic=[]`
- `missing_time=[]`
- `missing_url=[]`

人工查看生成图：

- `ai_digest_00_cover.png`：没有 `Auto Redbook AI Brief`，没有 `本期整理 10 条动态`，封面展示 `今日重点`。
- `ai_digest_01.png`：每条动态都有发布时间和来源，底部没有旧来源提示。

## 注意

- 修复只影响新生成的 `每日AI讯息` 草稿。旧本地草稿或已经上传到小红书创作者中心的旧草稿不会自动改图。
- 本地 fallback 是保守中文化，不会编造候选之外的事实；如果要获得更自然的中文简报，应优先使用可用 LLM，例如本次验证的阿里云 `glm-5.2`。
