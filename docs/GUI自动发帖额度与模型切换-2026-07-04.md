# GUI 自动发帖额度与模型切换（2026-07-04）

## 背景

本次修复目标是让“自动发帖”页右下角的模型额度面板真正可用：

- 同步 Aliyun 和 Volcengine 当前账号下仍有免费额度记录的模型。
- 在 GUI 中用横条展示剩余额度。
- 模型名提供按钮式点击能力，点击后切换左侧的供应商与模型选择。
- 登录失败或控制台风控导致的空快照不能覆盖上一份有效额度。

额度读取仍然只访问官方控制台页面和控制台自身接口，不调用 LLM 或生图推理接口，因此不会为了查额度消耗 token 或图片次数。

## 当前同步逻辑

`sync-quotas` 默认进入全量模式：

```powershell
.\.venv\Scripts\python.exe -m apps.cli sync-quotas --login-hold 600 --wait-timeout 180
```

如需保留旧的指定模型查询，可使用：

```powershell
.\.venv\Scripts\python.exe -m apps.cli sync-quotas --target-only --aliyun-model glm-5.2 --volcengine-model glm-5.2
```

Aliyun 读取 Bailian 控制台 `freeTierQuotas`，筛选 `quotaInitTotal > 0` 或仍有剩余额度的记录。Volcengine 读取 Ark 控制台 `ListModelChargeItems` / `GetModelChargeItem`，筛选 `ResourcePackItems` 中 `Type=FreeInference` 的资源包。

## GUI 行为

- “自动发帖”页右下角显示 `模型额度`，其他页仍显示记录详情。
- `同步免费额度` 调用 `sync-quotas`，默认用可见浏览器，方便 Aliyun 首次登录或风控验证。
- `刷新本地额度` 从 `data/quota/*_quota_*.json` 读取最新有效快照。
- 如果最新快照没有 `records`，GUI 会跳过它，回退到上一份有效快照。
- 只有 `status=available`、`remaining > 0` 且 `kind` 为 `llm` 或 `image` 的行可点击。
- 点击 LLM 行：切换左侧 `LLM 供应商` 和 `LLM 模型`。
- 点击 image 行：切换左侧 `图片来源` 和 `生图模型`，并自动使用 `assets/empty/*` 触发自动配图。
- `unknown` 类型额度默认只展示；如果模型名能明确识别为生图模型（例如 `seedream`、`seededit`、`qwen-image`、`t2i`、`i2i`），GUI 会将其安全推断为 `image` 并允许点击切换。
- `t2v`、`i2v`、`seedance`、`seed3d`、`3d`、`video` 等暂未接入的非文生图模型仍只展示，不会被点击写入生成配置。

## 2026-07-04 额度搜索与排序补充

### GUI 行为

- 自动发帖页右下角 `模型额度` 面板新增 `搜索`、`排序` 和 `倒序` 控件。
- `搜索` 支持按模型名、平台、类型、状态、单位、当前展示值、快照名过滤；多个搜索词按空格拆分，必须同时命中。
- `排序` 支持 `平台 / 类型 / 模型`、`剩余额度`、`剩余比例`、`模型名`、`平台`、`状态`。
- 数值排序时，未知额度始终排在最后，避免 `平台未返回`、`网页未展示` 一类记录盖过可用额度。
- 搜索或排序变化只重绘当前本地快照，不会触发控制台同步；点击 `刷新本地额度` 或 `同步免费额度` 后会继续套用当前搜索与排序条件。

## 2026-07-04 补充：进度输出与可点击额度修复

本轮继续优化两个实际使用问题：

- CLI 长任务现在按阶段输出 `[command] stage=... | in_progress/success/failed`，覆盖自动生成、草稿发布/删除、已发布数据更新、Aliyun/Volcengine 额度同步等入口。
- GUI 后台任务会解析这些 stage 事件，状态栏和心跳日志显示“当前步骤”，不再只提示程序仍在运行。
- 模型额度横条的整行区域都可点击，不再只依赖模型文字本身的窄命中区域。
- 可点击判断新增模型名推断：`kind=unknown` 但名称能明确识别为 `seedream` / `seededit` / `qwen-image` 等生图模型时，允许写入“图片来源/生图模型”；视频、3D、未接入类型仍不可点击。
- 额度行的类别文案新增 `image · 推断`、`仅展示`、`llm · 不可用` 等状态，明确区分“可以点击写入配置”和“账号有额度但当前软件未接入该生成类型”。
- Aliyun 采集新增 `reload_after_login` 重试：如果同一轮采集中先捕获到 `NOT_LOGINED`，后捕获到 `ALIYUN_LOGINED`，但页面仍显示空资源，程序会重新打开免费额度页再读一次，避免登录完成后停留在旧空页面。

## 2026-07-04 补充：额度行长文本布局修复

截图反馈中，长模型名会被左侧窄列截断，右侧 `使用量 / 总量` 也会因为固定 `width=96` 在空格处折成两行。修复如下：

- 新增 `quota_dashboard_layout(width)`，按当前 Canvas 宽度计算模型列、进度条列和额度值列。
- 新增 `quota_dashboard_row_title(row, model_width)`，模型名过长时采用中间省略，保留模型名前缀和版本尾部。
- 额度值改为紧凑格式，例如 `500000/500000 token`，避免斜杠两侧空格触发自动换行。
- Canvas 绘制右侧额度值时不再设置小宽度，改为右对齐单行文本。
