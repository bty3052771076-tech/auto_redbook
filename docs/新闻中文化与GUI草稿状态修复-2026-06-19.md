# 新闻中文化与 GUI 草稿状态修复（2026-06-19）

## 修复目标

本次修复针对每日新闻自动化链路和图形化界面：

- 英文新闻必须由 LLM 改写为简体中文；LLM 不可用时使用中文保守兜底，不直接发布英文标题或英文摘要。
- 正文结构固定为“要点摘要 / 新闻内容 / 点评 / 发布时间 / 来源”，其中摘要约 50 字，新闻内容约 200 字。
- 发布正文不再输出 URL；来源只显示来源名称。原始网址保存在本地 `data/posts/<post_id>/post.json` 的 `platform.news.source_url` 和 `platform.news.picked.url`。
- GUI 草稿处理页显示“已上传至小红书草稿 / 未上传”、上传时间、本地更新时间、最近执行结果、素材数量和正文预览。
- 提供工作区内快速启动程序，不安装任何内容到 C 盘。

## 内容生成规则

每日新闻提示词已强化为：

- 所有输出必须为简体中文。
- 如果原始材料是英文新闻，先翻译并用中文新闻写法改写，不保留英文长句。
- 不得新增事实、数字、人物关系或因果判断；信息不足时使用保守表述。
- 正文不得输出 URL、网址或 `http(s)` 链接。
- 来源行只写来源名称，例如 `来源：AP News`。

保存前还有一层本地清洗：

- 自动移除正文中的 URL。
- 自动重写末尾来源行为 `来源：<来源名称>`。
- 保留 `发布时间` 和 `来源` 元信息，避免正文过长时被截断。

## GUI 变化

`python -m apps.gui` 打开后：

- 顶部按钮“打开小红书创作平台”会打开图文发布页 `https://creator.xiaohongshu.com/publish/publish?target=image`。
- “草稿处理”页的帖子下拉框会显示上传状态与时间。
- 选择某条草稿后，下方“草稿详情”会显示标题、`post_id`、本地状态、上传状态、上传时间、本地更新时间、最近执行、素材数量和正文预览。
- “删除草稿”页仍建议先保持 `dry-run`，确认列表后再取消 `dry-run` 并勾选 `--yes`。
