# GNews 新闻源接入与阶段化错误提示

## 目标

本次接入新增 GNews 作为“每日新闻”的备用新闻源，并在 CLI 失败时明确输出失败阶段：

- `stage=获取新闻`
- `stage=LLM`
- `stage=VLM生图`
- `stage=上传`

## 密钥安全

不要把真实 API Key 写入仓库文件。推荐使用当前终端会话环境变量：

```powershell
$env:GNEWS_API_KEY="YOUR_GNEWS_API_KEY"
```

如必须使用本机文件，可复制 `docs/gnews_api-key.example.md` 为 `docs/gnews_api-key.md` 后填写。`docs/*api-key.md` 已在 `.gitignore` 中忽略，不应提交到 Git。

## 新闻源配置

强制使用 GNews：

```powershell
$env:NEWS_PROVIDER="gnews"
$env:GNEWS_API_KEY="YOUR_GNEWS_API_KEY"
$env:GNEWS_LANG="en"
$env:GNEWS_COUNTRY="us"
```

默认自动模式：

```powershell
Remove-Item Env:NEWS_PROVIDER -ErrorAction SilentlyContinue
```

自动模式会按以下顺序尝试：

1. `file`：当设置了 `NEWS_CANDIDATES_FILE` 时优先使用本地已核验新闻文件
2. `newsapi`：当检测到 `NEWS_API_KEY` / `NEWSAPI_API_KEY`
3. `gnews`：当检测到 `GNEWS_API_KEY` / `GNEWS_TOKEN`
4. `juhe`：当检测到 `JUHE_NEWS_APPKEY` / `JUHE_FINANCE_NEWS_APPKEY`

`gdelt` 已移除，不再作为无 key 回退源。

## 失败提示

CLI 报错统一格式：

```text
error: stage=获取新闻 | no news returned (...)
error: stage=LLM | LLM api_key missing (...)
error: stage=VLM生图 | Aliyun image api_key missing (...)
error: stage=上传 | draft save verification failed
```

这样可以直接判断是哪一段断了：

- `获取新闻`：新闻 API key、额度、限流、查询词、候选文件等问题
- `LLM`：文案模型 key、模型名、额度、限流或兼容接口问题
- `VLM生图`：阿里云生图 key、模型名、超时、下载图片失败等问题
- `上传`：小红书登录态、页面结构、浏览器 profile、网络或保存草稿失败

## 验证

本次新增/更新的测试覆盖：

- `NEWS_PROVIDER=gnews` 能映射 GNews 返回的文章为项目内部 `NewsItem`
- 自动模式在 NewsAPI 未配置时能使用 GNews
- CLI 能格式化阶段化错误
- VLM 生图 key 缺失不会被误判为 LLM 阶段
