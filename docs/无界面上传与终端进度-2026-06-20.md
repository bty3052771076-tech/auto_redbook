# 无界面上传与终端进度说明（2026-06-20）

## 背景

之前从本地上传到小红书草稿箱时，Playwright 总是以可视浏览器启动。现在已新增可选的无界面模式，适合已经登录过小红书、希望后台保存草稿的场景。

## 使用前提

- 必须已经在工作区 Chrome profile 登录小红书：`data/browser/chrome-profile`。
- 首次登录、扫码、验证码、账号风控校验仍需要可视浏览器完成。
- 如果使用 `XHS_CDP_URL` 连接已经打开的 Chrome，`--headless` 不会接管该浏览器是否可见。

## CLI 用法

单条本地草稿上传：

```powershell
.\.venv\Scripts\python.exe -m apps.cli run <post_id> --headless --login-hold 0 --wait-timeout 300 --force
```

自动生成新闻并上传草稿：

```powershell
.\.venv\Scripts\python.exe -m apps.cli auto --title "每日新闻" --prompt "选择适合小红书图文的科技、社会或国际新闻，摘要约50字，正文约200字，内容必须严谨真实。" --assets-glob "assets/empty/*" --count 1 --login-hold 0 --wait-timeout 300 --force --headless
```

也可以用环境变量开启：

```powershell
$env:XHS_HEADLESS="1"
.\.venv\Scripts\python.exe -m apps.cli run <post_id> --login-hold 0 --wait-timeout 300 --force
```

删除草稿也支持无界面：

```powershell
.\.venv\Scripts\python.exe -m apps.cli delete-drafts --draft-type image --limit 0 --dry-run --headless --login-hold 0 --wait-timeout 300
```

## GUI 用法

- `自动发帖` 页：勾选“无界面上传”。
- `草稿处理` 页：勾选“无界面上传”后运行上传。
- `删除草稿` 页：勾选“无界面运行 (--headless)”。

GUI 会把底层 CLI 输出同步到日志区，因此可以看到上传步骤与进度。

## 终端进度格式

上传时会实时输出类似内容：

```text
[xhs-upload] launch: in_progress | data\browser\chrome-profile | headless=True | post_id=<post_id>
[xhs-upload] upload_images: in_progress | 1 files | post_id=<post_id>
[xhs-upload] wait_for_upload_complete: in_progress | uploaded=0/1 | post_id=<post_id>
[xhs-upload] wait_for_upload_complete: success | uploaded=1/1 | post_id=<post_id>
```

任务结束后仍会保留原来的 execution 步骤记录，位置在：

```text
data/posts/<post_id>/executions/
```

## 注意事项

- 如果 `--headless` 下提示登录失败或找不到发布页，请先取消 `--headless`，用 GUI 的 `登录/检查Profile` 或 `Open-XHS-Creator.cmd` 完成登录。
- 如果小红书页面策略变化导致 headless 被限制，保留可视浏览器模式作为稳定兜底。
- `--login-hold` 在 headless 模式下不会弹出可扫码窗口，通常应设为 `0`。
