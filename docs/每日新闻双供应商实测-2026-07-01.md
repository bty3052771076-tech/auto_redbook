# 每日新闻双供应商实测（2026-07-01 / 2026-07-02）

## 目标

验证“每日新闻”在两个供应商组合下的生成和草稿保存链路：

- Aliyun：`glm-5.2` + `qwen-image-2.0-pro-2026-04-22`
- Volcengine：`doubao-seed-2-1-turbo-260628` + `doubao-seedream-5-0-lite-260128`

新闻方向固定为：

```text
财经产业 / 公司政策 / 市场变化
```

新闻候选固定为 2026-07-01 的新浪财经稿：

```text
八部门发文推动工业互联网高质量发展
https://finance.sina.com.cn/headline/2026-07-01/doc-iniffumk6451530.shtml
```

## Aliyun 实测

运行方式：

```powershell
$env:NEWS_PROVIDER="file"
$env:NEWS_CANDIDATES_FILE="data/news_candidates/volcengine_focus_20260701.json"
$env:LLM_PROVIDER="aliyun"
$env:ALIYUN_LLM_MODEL="glm-5.2"
$env:ALIYUN_LLM_MODELS="glm-5.2"
$env:IMAGE_PROVIDER="aliyun"
$env:ALIYUN_IMAGE_MODEL="qwen-image-2.0-pro-2026-04-22"
$env:ALIYUN_IMAGE_MODELS="qwen-image-2.0-pro-2026-04-22"
.\.venv\Scripts\python.exe -m apps.cli auto --title "每日新闻" --prompt "财经产业 / 公司政策 / 市场变化" --evaluation-viewpoint "无视角评价" --assets-glob "assets/empty/*" --count 1 --login-hold 0 --wait-timeout 600 --force --headless
```

结果：

- `post_id`: `88dff7775f204217b74d68ed23f6b27a`
- 标题：`八部门定调工业互联网发展目标`
- 状态：`saved_as_draft`
- 平台验证：`verify_draft_box_item: success | verified_title=True cover_ready=True`
- 图片：`data/posts/88dff7775f204217b74d68ed23f6b27a/assets/ai_aliyun_20260701_111946.png`

视觉检查：

- 图片非空，主体与“政策文件 / 工业互联网”相关。
- 图片中出现了较大的中文标题元素；虽可用作草稿验证，但后续若追求无字图，应继续优化 qwen-image 提示词，避免“文件标题/海报/文书文字”等诱发文字的描述。

## Volcengine 实测

生成命令使用临时环境变量传入 Ark API Key，未写入仓库文件。

运行方式：

```powershell
$env:NEWS_PROVIDER="file"
$env:NEWS_CANDIDATES_FILE="data/news_candidates/volcengine_focus_20260701.json"
$env:LLM_PROVIDER="volcengine"
$env:VOLCENGINE_LLM_MODEL="doubao-seed-2-1-turbo-260628"
$env:VOLCENGINE_LLM_MODELS="doubao-seed-2-1-turbo-260628"
$env:IMAGE_PROVIDER="volcengine"
$env:VOLCENGINE_IMAGE_MODEL="doubao-seedream-5-0-lite-260128"
$env:VOLCENGINE_IMAGE_MODELS="doubao-seedream-5-0-lite-260128"
$env:VOLCENGINE_IMAGE_SIZE="1440x2560"
.\.venv\Scripts\python.exe -m apps.cli auto --title "每日新闻" --prompt "财经产业 / 公司政策 / 市场变化" --evaluation-viewpoint "无视角评价" --assets-glob "assets/empty/*" --count 1 --login-hold 0 --wait-timeout 600 --force --headless --dry-run
```

结果：

- `post_id`: `09bd1a6f95a14dfb86d6e9f882315886`
- 标题：`八部门发文推进工业互联网高质量发展`
- 生成验证：LLM 与 Seedream 图片均成功。
- 图片：`data/posts/09bd1a6f95a14dfb86d6e9f882315886/assets/ai_volcengine_20260701_112534.jpg`

随后对同一 post 执行保存草稿：

```powershell

```

平台草稿箱 dry-run 验证：

本地状态已按上述平台证据同步为：

- 状态：`saved_as_draft`
- `uploaded=True`
- `uploaded_at=2026-07-02T00:52:35Z`

视觉检查：

- 图片非空，主体与“工业互联网 / 算力基础设施 / 产业升级”相关。
- 画面基本无明显文字，更适合作为新闻配图。

## 发现与修复

1. 公开“仅生成”入口已移除：

```powershell
.\.venv\Scripts\python.exe -m apps.cli create --title "每日新闻"
```

结果：

```text
No such command 'create'.
```

2. Volcengine 草稿保存过程中发现发布页 `page.goto` 仍使用固定 30 秒默认超时。已新增 `_context_default_timeout_ms(...)`，让 Playwright 默认超时跟随 `--wait-timeout`，最低仍保留 30 秒。

3. Volcengine 草稿保存后，平台实际已保存，但即时验证在草稿列表刷新前误判失败。已修复 `_open_draft_list_and_check_saved(...)`，在 fallback 草稿列表中按 `wait_timeout_ms` 做短轮询。
