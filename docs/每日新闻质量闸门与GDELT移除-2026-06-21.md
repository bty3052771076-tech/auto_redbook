# 每日新闻质量闸门与 GDELT 移除

日期：2026-06-21

## 背景

实机查看小红书创作者中心最新 5 条草稿后发现：

- 草稿标题混入阿拉伯文、越南文或“原文摘录”。
- 正文出现“在信息仍有限的情况下……”等空泛兜底句。
- 正文混入网页导航、分享按钮、字体控制等噪声。
- 点评会把 AI/版权、体育青训等模板套到不相关事件上。
- 此前自动新闻源在 NewsAPI / GNews 不可用时会回退到 GDELT，而 GDELT 常只提供标题或低质量摘录，容易导致上述问题。

## 本次修复

- 移除 GDELT 生产路径：`NEWS_PROVIDER=gdelt` 现在会报不支持。
- `NEWS_PROVIDER=auto` 会优先尝试已配置的 NewsAPI / GNews / Juhe；这些来源不可用时，最后回退到无需 Key 的 `hotnews` 热榜候选源，但不再回退到 GDELT。
- 保留 `NEWS_PROVIDER=file`，用于加载人工核验过的真实新闻候选文件。
- 标题质量闸门新增：拒绝“原文摘录”、外文脚本泄漏、日文假名、过少中文字符。
- 正文质量闸门新增：拒绝空正文、外文脚本泄漏、信息不足兜底句。
- 网页噪声清理新增：分享按钮、微信扫码、普通话/广东话/字号/超大等站点控件。
- 常见繁体字会做轻量简体化，降低繁体标题进入小红书标题的概率。
- 点评一致性增强：NASA/空间站/世界杯用球事件不再套用体育竞技/青训模板。
- 单条每日新闻路径也增加最终质量拦截，避免坏内容落盘并上传。

## 使用建议

推荐优先使用：

```powershell
$env:NEWS_PROVIDER="gnews"
$env:GNEWS_API_KEY="YOUR_GNEWS_API_KEY"
```

或：

```powershell
$env:NEWS_PROVIDER="newsapi"
$env:NEWS_API_KEY="YOUR_NEWS_API_KEY"
```

或：

```powershell
$env:NEWS_PROVIDER="juhe"
$env:JUHE_NEWS_APPKEY="YOUR_JUHE_NEWS_APPKEY"
$env:JUHE_FINANCE_NEWS_APPKEY="YOUR_JUHE_FINANCE_NEWS_APPKEY"
```

当在线新闻 API 临时不可用时：

```powershell
$env:NEWS_PROVIDER="file"
$env:NEWS_CANDIDATES_FILE="data/news/manual_candidates_YYYYMMDD.json"
```

## 国内新闻 API 状态

聚合数据「新闻头条」和「财经新闻」已接入为 `NEWS_PROVIDER=juhe`。

原因：

- 国内平台，文档和申请流程相对清晰。
- 新闻头条覆盖国内、国际、体育、娱乐、科技等资讯。
- 官方说明新闻头条更新周期为 5-30 分钟。
- 新闻头条支持先取列表、再按 `uniquekey` 查询详情，减少只拿标题/摘要导致的低质草稿。
- 财经新闻接口返回标题、来源、图片、链接和发布时间，适合财经类 query 备用。

备选：天聚数行 TianAPI「国内新闻」。

- 优点：国内新闻接口清晰，普通会员页面显示 100 次/天。
- 风险：官方页面写明“仅限用于内部数据分析和机器学习，不得用于终端展示”。如果用于生成并发布小红书内容，必须先确认授权边界。

## 验证

新增和更新的核心测试覆盖：

- 自动模式不再回退 GDELT；最后兜底为 `hotnews` 热榜候选源。
- `NEWS_PROVIDER=gdelt` 直接报不支持。
- 外文标题和“原文摘录”被质量闸门拦截。
- 站点噪声会被清理或替换为可信上下文。
- 错配点评会被删除或改写为与事实相关的点评。
