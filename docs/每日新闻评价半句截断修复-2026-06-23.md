# 每日新闻评价半句截断修复（2026-06-23）

## 现象

部分每日新闻正文最后可能出现不完整句子，例如：

```text
评价：
此次全系列大尺寸OLED面板获得全球首个“完美色彩/亮度”认证，体现了LG Display在OLED技术研发上的 发布时间：2026-06-22
```

## 原因

这类问题可能由 LLM 输出被截断触发。项目当前 LLM 调用默认设置为 `max_tokens=25565`，可以降低模型提前截断的概率；但更直接的问题是后处理没有把截断半句清掉：

- LLM 可能在 `评价` 字段中输出到半句结束。
- 后续 `_ensure_news_publish_date(...)` 会补 `发布时间`。
- 旧清洗逻辑没有把误入 `评价` 的 `发布时间` 和半句尾巴删除。

所以它不应只归因于 `max_tokens`。即使模型被截断，落盘前也应该保证最终正文没有半句。

## 修复

- 新增评价专用清洗：去掉误入评价字段的 `发布时间` / `日期` / `来源`。
- 如果评价末尾是明显半句，例如以 `的`、`上的`、`在`、`体现了` 等结尾，则删除该评价。
- 如果评价有完整前句，则保留完整句，删除后面的残缺尾巴。
- 无法可靠修复时允许 `评价` 为空，避免发布不通顺内容。
