# LLM 输出 token 上限调整（2026-06-23）

## 变更

统一草稿生成入口 `src/llm/generate.py::generate_draft()` 的 `max_tokens` 默认值已从 `1200` 调整为 `25565`，并在 2026-07-01 进一步调整为 `60000`。

## 影响范围

- 普通图文草稿生成。
- 每日新闻草稿生成，因为每日新闻最终也会走 `generate_draft()` 调用 LLM。
- 每日假新闻草稿生成。

## 注意事项

`max_tokens=60000` 表示本项目向 OpenAI-compatible LLM 客户端请求的最大输出 token 数。最终是否能实际输出到这个长度，仍取决于供应商、模型上下文窗口、账号额度和服务端限制。

如果某个模型不支持这么高的输出上限，终端会在 LLM 阶段显示失败原因，工作流会按既有逻辑尝试备用模型或离线兜底。

这个调整可以降低正文被模型提前截断的概率，但不能替代正文质量闸门。每日新闻落盘前仍会清理半句、提示词泄漏、URL、无关评论和格式异常。
