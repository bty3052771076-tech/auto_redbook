# 每日新闻专业写作规则与关键词命名（2026-07-19）

## 目标

1. 参考专业新闻报道的事实组织方式，优化每日新闻的内部生成规则。
2. 将 GUI 和 CLI 中原称为“提示词”的选题输入统一改为“关键词”，明确其只负责新闻检索和候选筛选。

## 参考方法

本轮阅读了 [美联社经济报道](https://apnews.com/article/inflation-economy-iran-trump-unemployment-ai-c8ed0b54d80fe1bdaa5edcef671e6608)、[NPR 体育报道](https://www.npr.org/2026/07/17/nx-s1-5897510/bts-bieber-madonna-shakira-world-cup-halftime-show) 和 [新华网新闻原文](https://www1.xinhuanet.com/politics/20260717/ac6ecfcb7e594939bab176be1ade2ccf/c.html)。仅提炼其通用写法，不复制句子、结构或任何具体事件。

提炼出的内部写作标准：

1. 内容首句直接交代最重要的已证实事实，后续按重要性递减补充主体、时间、变化、数据和必要背景。
2. 明确区分已发生事实、相关方表态、计划安排和不确定结果；不把预测或单方观点写成既成事实。
3. 背景只保留解释本次变化所必需的内容，避免导航式堆砌和情绪化修辞。
4. 评价仅在材料足以支持时说明已知影响与待观察变量，不给投资建议，不预设立场，不使用号召式语言。

内部模板不硬编码任何新闻标题、机构、人物、数据或具体事件。运行时新闻材料仍以候选的标题、来源、日期、摘要和正文摘录注入；模板本身只提供通用的写作与事实约束。

## 实现

### 内部生成规则

`src/workflow/create_post.py` 新增 `_daily_news_professional_reporting_instruction()`，并在 `_daily_news_prompt()` 中使用。它约束：

- 事实优先、按重要性递减的结构；
- 首句直接写已证实的事件；
- 计划、推断和不确定结果必须保留限定词；
- 评价必须有材料支撑并保持边界；
- 不使用感叹、设问、口号、比喻、泛泛判断或情绪化措辞。

模板中的候选筛选输入改称“检索关键词（仅用于选题相关性，不得写入正文）”。

### GUI 与 CLI

- GUI 自动发帖页标签从“提示词”改为“关键词”，每个输入框说明为“检索关键词”。
- 单条/多条新闻材料模式的说明同步改为“关键词”。
- GUI 启动参数优先读取 `AUTO_REDBOOK_GUI_KEYWORDS`，旧的 `AUTO_REDBOOK_GUI_PROMPT` 仍保留兼容。
- CLI `auto` 和 `check-sources` 的主参数为 `--keywords`。
- CLI 保留 `--prompt` 作为兼容别名，旧脚本不需要立即迁移。

示例：

```powershell
.\.venv\Scripts\python.exe -m apps.cli auto `
  --title "每日新闻" `
  --keywords "财经产业 公司政策 市场变化 / 国际安全 能源价格" `
  --count 3 `
  --headless `
  --login-hold 0
```

## 兼容性

内部 Python 函数和本地运行记录仍使用既有的 `prompt` 字段名，避免无关的数据迁移；这是实现细节，不再作为 GUI 或 CLI 的用户概念。对外使用时应优先填写“关键词”或 `--keywords`。
