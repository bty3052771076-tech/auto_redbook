# 每日新闻中文来源扩展与筛选诊断（2026-07-11）

## 问题

提示词为“世界杯”时，自动流程可能报告 `0 within 14 days`。这不等于没有相关新闻：原有无 Key 链路主要依赖国际 RSS、BBC 和热榜；热榜记录常没有标准发布时间，随后会被日期窗口过滤。

## 修改

自动模式新增 `google_rss_cn` 中文区域 Google News RSS（`hl=zh-CN`、`gl=CN`、`ceid=CN:zh`），不需要 API Key，并保留 RSS 发布时间。国际 Google RSS、BBC RSS 继续作为补充，热榜仍只作为热度补充，不能绕过日期窗口。

自动源顺序为：已配置的 NewsAPI/GNews/聚合数据 -> 中文 Google RSS -> 国际 Google RSS -> BBC -> 热榜。来源健康记录会保存 `item_count`、`dated_count`、`url_count`，用于区分来源为空、缺少日期和日期筛选后不足。

## 验证

```powershell
.\\.venv\\Scripts\\python.exe -m apps.cli auto --title "每日新闻" --prompt "世界杯 体育 足球" --count 1 --assets-glob "assets/empty/*" --login-hold 0 --wait-timeout 600
```

查看 `data/source_health/daily_news.json`：`google_rss_cn` 的 `item_count` 是 RSS 返回数，`dated_count` 是可解析发布时间的数量。若两者为 0，才表示 RSS 不可达或没有召回，不能归因于 LLM。

本次没有写入 API Key。
