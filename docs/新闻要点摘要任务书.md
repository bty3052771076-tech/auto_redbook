# 新闻要点摘要任务书（每日新闻正文首行摘要）

## 1. 背景
当前“每日新闻”正文直接进入新闻内容与点评，缺少一个可快速扫读的关键信息总结。为了让读者在第一眼就抓住新闻核心，需要在正文开头增加一段 30 字左右的要点摘要。

## 2. 目标
1) 当 LLM 生成“每日新闻”正文时，**正文首行**输出“要点摘要：”+ 20-40 字中文摘要，概括新闻最重要部分，不做评价。
2) 若 LLM 未按格式输出，通过后处理兜底保证首行摘要仍会生成并置顶。
3) 保持现有“新闻内容/我的点评”结构不变，仅在前面新增一行摘要。

## 3. 非目标
- 不新增独立字段（仅在正文内呈现）。
- 不强制精确字数，只控制在 20-40 字范围内。
- 不改变非“每日新闻”的生成逻辑。

## 4. 设计与实现
### 4.1 提示词增强
- 在 `_daily_news_prompt()` 中新增硬性要求：
  - 首行必须输出“要点摘要：”+ 20-40 字摘要（不评价）。
  - 保持三段结构：要点摘要 / 新闻内容 / 我的点评。

### 4.2 兜底与规范化
- 新增 `_normalize_news_summary()`：
  - 去链接、压缩空白、去标点包裹、截断到 40 字以内。
- `_ensure_daily_news_sections()`：
  - 若正文缺摘要或结构不完整，自动生成摘要并补齐三段结构。
- `_daily_news_offline_body()`：
  - 离线兜底正文同样包含“要点摘要：”行。

## 5. 验收标准
1) 执行 `auto --title "每日新闻"` 生成的正文**首行**为“要点摘要：”且字数 20-40 字左右。
2) 若输入正文缺失摘要或仅有两段，`_ensure_daily_news_sections()` 会补齐摘要与三段结构。
3) 非“每日新闻”流程不受影响。

## 6. 测试计划
- 单元测试：更新 `tests/test_daily_news.py` 断言摘要与三段结构。
- 手动验证：生成 1 条“每日新闻”草稿，检查正文首行摘要是否存在且合理。
