# “仅生成”公开入口移除（2026-07-01）

## 背景

项目此前同时提供：

- GUI `仅生成` 页签：只生成本地 `data/posts/<post_id>/`，不上传。
- CLI `create` 命令：只生成本地草稿，不保存到小红书创作者中心草稿箱。

本次需求要求删除“仅生成”功能，并保证其他功能正常。因此调整后的主路径统一为：

```text
auto / 自动发帖 -> 生成内容 -> 校验 -> 保存到小红书创作者中心草稿箱
```

## 行为变化

- GUI 已删除 `仅生成` 页签和按钮。
- GUI `build_cli_args("create", ...)` 现在会报 `unsupported subcommand`。
- CLI 不再注册公开 `create` 命令，直接执行会返回 `No such command 'create'`。
- `auto` 仍保留内部生成阶段，确保每日新闻、每日AI讯息、普通图文生成后可以继续校验并保存草稿。

## 修改文件

- `apps/gui.py`：移除 `create` 参数构造分支；`配置` 页新增 Aliyun/Volcengine 额度查询入口。
- `apps/cli.py`：移除 `create` 的 Typer 命令注册。
- `tests/test_gui.py`：新增/更新 GUI 不接受 `create` 的回归测试。
- `tests/test_cli_ai_digest.py`：新增 CLI `create` 非公开命令回归测试。
- `README.md` 与相关 docs：不再把“只生成本地草稿”作为推荐或公开用法。

## 验证

公开 CLI 帮助：

```powershell
.\.venv\Scripts\python.exe -m apps.cli --help
```

结果：命令列表不再包含 `create`。

直接调用：

```powershell
.\.venv\Scripts\python.exe -m apps.cli create --title "每日新闻"
```

结果：

```text
No such command 'create'.
```

回归测试：

```powershell
.\.venv\Scripts\python.exe -m pytest tests\test_gui.py::test_build_cli_args_rejects_create_only tests\test_gui.py::test_gui_no_longer_exposes_create_only_tab tests\test_cli_ai_digest.py::test_create_command_is_not_public -q
```

结果：通过。
