# 每日AI讯息来源扩展与兜底分层（2026-07-06）

## 背景

`每日AI讯息` 需要继续提升国内、国外模型动态覆盖面，同时避免 Hugging Face 这类综合模型发布站点抢占官方模型源的位置。

本次调整目标：

- 扩展国内模型源。
- 扩展国外模型源。
- 将 Hugging Face 作为最后兜底，不作为默认主源抢位。
- 过滤 HTML 页面中常见的营销标题、模型总览、导航和纯 `Release Notes` 噪声。

## 来源分层

### 第一层：官方模型源

默认优先抓取官方源和官方 GitHub release 源：

- 国外：OpenAI、Anthropic、Google DeepMind、Google Gemini、Meta AI、Microsoft AI、NVIDIA、Mistral AI、xAI、Cohere、Amazon Nova、AI21 Labs、Perplexity Sonar、Stability AI、Black Forest Labs / FLUX、Runway、Luma AI、Ideogram、Recraft。
- 国内：阿里云百炼 / Qwen、Qwen GitHub releases、智谱 GLM、智谱 ZCode、DeepSeek、MiniMax、火山方舟 / 豆包、腾讯混元、阶跃星辰、ByteDance Seed、百度千帆 / 文心、月之暗面 Kimi、讯飞星火、华为盘古、商汤日日新 SenseNova、零一万物 Yi、01.AI GitHub releases、百川 GitHub releases、书生浦语 InternLM GitHub releases、OpenBMB MiniCPM / MiniCPM-V GitHub releases、昆仑万维 Skywork、快手可灵 Kling。

### 第二层：AI HOT / 搜索补充

官方源不足或无法满足配额时，继续使用 `aihot-daily` 和新闻搜索补充。

### 第三层：综合模型发布兜底

Hugging Face 不再作为默认官方主源，而是 `aggregator`：

- `huggingface`：`https://huggingface.co/blog/feed.xml`
- `github-ai`：`https://api.github.com/repos/huggingface/transformers/releases`

只有在官方源、AI HOT 和搜索补充后仍不足以满足最少条数或国内/国外配额时，才会抓取这些综合源。

## 配置

默认不需要配置。

如需指定官方主源：

```powershell
$env:AI_DIGEST_PRIMARY_SOURCES="openai,anthropic,qwen-blog,zhipu-glm,doubao"
```

如需指定补充源：

```powershell
$env:AI_DIGEST_SOCIAL_SOURCES="aihot-daily"
```

如需指定 Hugging Face 兜底源：

```powershell
$env:AI_DIGEST_AGGREGATOR_SOURCES="huggingface,github-ai"
```

## 实现文件

- `src/ai_digest/sources.py`
  - 新增 `aggregator` source kind。
  - 新增 `qwen-blog`、`qwen-github`、`tencent-hunyuan`、`stepfun`、`mistral`、`xai`、`cohere`。
  - 继续补充 `iflytek-spark`、`huawei-pangu`、`sensetime-sensenova`、`01ai-yi`、`01ai-yi-github`、`baichuan-github`、`internlm-github`、`minicpm-github`、`minicpm-v-github`、`skywork`、`kling`。
  - 继续补充 `google-gemini`、`amazon-nova`、`ai21`、`perplexity-sonar`、`stability-ai`、`black-forest-labs`、`runway`、`luma-ai`、`ideogram`、`recraft`。
  - `huggingface`、`github-ai` 改为最后兜底的 aggregator。
- `src/ai_digest/collect.py`
  - 新增 `aggregator_backfill_used` metadata。
  - 采集顺序改为：官方源 -> AI HOT / 搜索补充 -> Hugging Face aggregator。
- `src/ai_digest/fetchers.py`
  - 过滤营销页标题、模型总览、开放平台文档中心、纯 `Release Notes` 等噪声。

## 抽样验证

本地抽样结果：

- `mistral` 使用 `https://mistral.ai/rss.xml`，可返回 RSS 条目。
- `huggingface` 和 `github-ai` 可返回大量兜底条目。
- `qwen-github` 当前 GitHub releases 返回 0 条，但阿里云百炼 / Qwen 官方更新源仍在第一层主链路。
- `xai` 页面在 Python 直接请求时可能返回 403，该错误会进入 metadata，不会中断整体生成。
