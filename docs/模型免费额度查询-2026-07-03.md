# 模型免费额度查询完善（2026-07-03）

## 背景

Aliyun 百炼和 Volcengine Ark 的剩余免费额度都属于账号控制台信息。当前程序继续采用“读取官方控制台页面”的方式，不调用 LLM 或生图推理接口，因此不会为了查询余额而消耗 token 或图片生成次数。

本次完善目标：

- 同时覆盖 LLM 和生图模型。
- 支持控制台常见表格顺序变化。
- 支持 `万 / 亿 / K / M` 等数量单位。
- 标记额度状态：`available / exhausted / expired / no_free_quota / unknown`。
- 保存本地原始快照，便于控制台 UI 变化时排查。

2026-07-03 晚间补充：

- Volcengine Ark 查询不再只读页面文本，会捕获官方控制台的 `ListModelChargeItems` / `GetModelChargeItem` JSON，并按目标模型名主动查询计费项。
- 如果 Ark 返回模型可用状态但没有返回 `InferenceFreeUsage`，状态为 `quota_not_returned`，不能视为免费额度同步成功。
- Aliyun 百炼会遍历免费额度页的常见分类标签，并修复 `剩118,817/共1,000,000 2026/09/01` 这类行被日期误解析的问题。
- Aliyun 百炼内部网关如果仍返回 `BailianGateway.Login.NotLogined`，状态会写入 `errors`，避免把登录态问题误判为无额度。

## CLI 使用

Aliyun 百炼：

```powershell
.\.venv\Scripts\python.exe -m apps.cli aliyun-quota --model glm-5.2 --model qwen-image-2.0-pro-2026-06-22 --login-hold 600 --wait-timeout 120 --save-raw
```

Volcengine Ark：

```powershell
.\.venv\Scripts\python.exe -m apps.cli volcengine-quota --model glm-5.2 --model deepseek-v4-pro --model deepseek-v4-flash --model doubao-seedream-5-0-lite-260128 --login-hold 600 --wait-timeout 120 --save-raw
```

首次查询建议不要加 `--headless`，在弹出的浏览器里完成登录。登录态保存在：

- `data/browser/aliyun-console-profile`
- `data/browser/volcengine-console-profile`

后续登录态有效时，可使用：

```powershell
.\.venv\Scripts\python.exe -m apps.cli volcengine-quota --model glm-5.2 --headless --login-hold 0 --wait-timeout 120 --save-raw
```

## 快照

加 `--save-raw` 后，程序会在 `data/quota/` 写入 JSON 快照：

```text
data/quota/aliyun_quota_YYYYmmdd_HHMMSS.json
data/quota/volcengine_quota_YYYYmmdd_HHMMSS.json
```

快照包含：

- `provider`
- 官方页面 URL
- 解析后的 `records`
- 原始可见文本 `raw_text`
- 错误列表 `errors`

如果需要指定目录：

```powershell
.\.venv\Scripts\python.exe -m apps.cli aliyun-quota --save-raw --snapshot-dir output/quota_debug
```

## 输出字段

| 字段 | 含义 |
|---|---|
| `model` | 模型名 |
| `kind` | `llm` / `image` / `unknown` |
| `status` | `available`、`exhausted`、`expired`、`no_free_quota` 或 `unknown` |
| `remaining` | 剩余额度 |
| `used` | 已用额度 |
| `total` | 总额度或免费额度 |
| `unit` | `token`、`Tokens`、`张` 等 |
| `expires_at` | 到期日期 |

`unknown` 表示控制台可见文本无法稳定解析。`quota_not_returned` 表示官方控制台接口返回了模型元数据，但没有返回免费额度字段。`not_found` 表示目标模型没有出现在当前可见或接口返回的免费额度列表中。此时以官方控制台页面为准，并查看 `data/quota/` 中保存的快照排查。

## 本轮实测结果

2026-07-03 18:59 左右，Volcengine Ark 使用已登录的 `data/browser/volcengine-console-profile` 查询：

- `glm-5.2` -> 控制台实际模型 `glm-5-2`，状态 `quota_not_returned`。
- `deepseek-v4-pro` -> 状态 `quota_not_returned`。
- `deepseek-v4-flash` -> 状态 `quota_not_returned`。
- `doubao-seedream-5-0-lite-260128` -> 控制台实际模型 `doubao-seedream-5-0`，状态 `quota_not_returned`。

这些模型在 Ark 计费项接口中可匹配到模型元数据，但没有 `InferenceFreeUsage` 字段，因此程序会以失败状态退出并写入：

```text
free quota not returned for requested Volcengine models: ...
```

同一账号下，接口能对部分其他模型返回免费额度字段，例如 `doubao-pro-*` / `doubao-lite-*` 等模型返回 `500000`，说明解析链路有效；目标模型没有返回字段不是解析器漏读。

Aliyun 百炼在同一时间段的实测结果：

- `--headless` 可明确检测到登录态不可用。
- 可见浏览器模式会进入阿里云登录/风控流程；登录完成前无法稳定读取百炼内部网关。
- 曾读取到免费额度表中的 `qwen3.7-plus`、`glm-5.1` 等模型行，但目标 `glm-5.2` 与 `qwen-image-2.0-pro-2026-06-22` 尚未在稳定登录态下确认。

因此 Aliyun 当前同步结果以最新快照为准：如果 `errors` 包含 `Aliyun console login required` 或 `bailian_internal_not_logged_in`，需要先在 `data/browser/aliyun-console-profile` 的可见浏览器里完成登录和验证码/风控校验，再重新运行查询。

## 2026-07-03 补充：严格网页可见模式

为满足“可以不用接口，直接用网页上的信息获取免费额度”的需求，新增严格模式：

```powershell
.\.venv\Scripts\python.exe -m apps.cli aliyun-quota --model glm-5.2 --model qwen-image-2.0-pro-2026-06-22 --visible-only --save-raw
.\.venv\Scripts\python.exe -m apps.cli volcengine-quota --model glm-5.2 --model deepseek-v4-pro --model deepseek-v4-flash --model doubao-seedream-5-0-lite-260128 --visible-only --save-raw
```

严格模式的行为：

- `source_mode` 写入 `visible_page_only`。
- 只解析浏览器页面中可见的 DOM 文本和表格行。
- 不注册 console API response/request 捕获。
- 不主动调用 Volcengine Ark 的 `ListModelChargeItems` / `GetModelChargeItem`。
- `console_api_payloads` 保持为空数组。
- 如果目标模型的免费额度未在网页可见区域展示，记录状态为 `not_visible_on_page`。

默认模式仍保留原逻辑：

- Aliyun：页面文本为主，同时可捕获控制台返回的非推理 JSON 作为登录/异常诊断。
- Volcengine：页面文本为主，必要时使用官方控制台 charge-item JSON 辅助判断模型可用性和 `InferenceFreeUsage` 是否返回。

新增 GUI 入口：

- 配置页的 Aliyun Bailian quota 区域新增 `Visible page only`。
- 配置页的 Volcengine Ark quota 区域新增 `Visible page only`。
- 勾选后 GUI 会向 CLI 追加 `--visible-only`。

新增状态含义：

| 状态 | 含义 |
|---|---|
| `not_visible_on_page` | 严格网页可见模式下，目标模型没有出现在当前网页可见的免费额度表格/文本中。此状态不代表模型一定没有免费额度，只代表页面没有直接展示可解析额度。 |
| `quota_not_returned` | 默认模式下，官方控制台接口返回了模型元数据，但没有返回 `InferenceFreeUsage` 免费额度字段。 |
| `not_found` | 默认模式下，目标模型既没有在可见页面文本中出现，也没有在辅助控制台返回中匹配到。 |

本轮实测：

- Volcengine 严格网页可见模式：
  - 命令：`volcengine-quota --model glm-5.2 --model deepseek-v4-pro --model deepseek-v4-flash --model doubao-seedream-5-0-lite-260128 --headless --login-hold 0 --wait-timeout 120 --save-raw --visible-only`
  - 快照：`data/quota/volcengine_quota_20260703_194846.json`
  - 结果：`records=4`，`console_api_payloads=0`，4 个目标模型均为 `not_visible_on_page`。
  - 结论：当前 Ark 网页没有直接以可见文本展示这些目标模型的免费额度；严格模式已正确拒绝使用控制台接口补数。
- Aliyun 严格网页可见模式：
  - 命令：`aliyun-quota --model glm-5.2 --model qwen-image-2.0-pro-2026-06-22 --headless --login-hold 0 --wait-timeout 120 --save-raw --visible-only`
  - 快照：`data/quota/aliyun_quota_20260703_194900.json`
  - 结果：`records=0`，`console_api_payloads=0`，错误为当前 Aliyun profile 在 headless 下未登录。
  - 结论：需要先用 `data/browser/aliyun-console-profile` 的可见浏览器完成登录/风控，再重新运行严格模式。

## 2026-07-04 补充：全量免费额度同步

新增默认全量模式：

```powershell
.\.venv\Scripts\python.exe -m apps.cli sync-quotas --login-hold 600 --wait-timeout 180
```

等价于 `--all-free`。如果只想查指定模型，使用：

```powershell
.\.venv\Scripts\python.exe -m apps.cli sync-quotas --target-only --aliyun-model glm-5.2 --volcengine-model glm-5.2
```

单平台也支持：

```powershell
.\.venv\Scripts\python.exe -m apps.cli aliyun-quota --all-free --login-hold 600 --wait-timeout 180 --save-raw
.\.venv\Scripts\python.exe -m apps.cli volcengine-quota --all-free --headless --login-hold 0 --wait-timeout 120 --save-raw
```

解析规则：

- Aliyun：从 Bailian 控制台返回的 `freeTierQuotas` 中提取免费额度记录；`quotaInitTotal > 0` 或仍有剩余额度的模型会进入快照。
- Volcengine：从 Ark 控制台 `ListModelChargeItems` / `GetModelChargeItem` 提取 `ResourcePackItems`，只把 `Type=FreeInference` 视为免费推理额度。
- `kind=unknown` 的模型仍保存在快照中用于排查，但 GUI 不会把它们作为可点击生成模型。
- GUI 加载快照时会跳过 `records=[]` 的失败快照，避免登录态错误覆盖上一份有效额度。

本轮实测有效快照：

```text

Volcengine: data/quota/volcengine_quota_20260704_002838.json records=61
```
