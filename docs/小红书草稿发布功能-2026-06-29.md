# 小红书创作者中心草稿发布功能（2026-06-29）

## 功能范围

本功能用于把已经保存到小红书创作者中心草稿箱的图文草稿自动发布到平台。

支持两种选择方式：

1. 按日期选择：根据本地上传到草稿箱的时间筛选，日期按北京时间 `YYYY-MM-DD`。
2. 按草稿选择：指定一个或多个本地 `post_id`，对应 `data/posts/<post_id>/post.json`。

默认建议先 dry-run，只预览和匹配草稿，不点击发布；确认无误后再正式发布。

## CLI 使用

预览今天可发布的本地草稿：

```powershell
.\.venv\Scripts\python.exe -m apps.cli publish-drafts --date 2026-06-29 --dry-run --login-hold 0 --wait-timeout 600
```

发布指定日期的草稿：

```powershell
.\.venv\Scripts\python.exe -m apps.cli publish-drafts --date 2026-06-29 --limit 3 --yes --login-hold 0 --wait-timeout 600
```

发布指定草稿：

```powershell
.\.venv\Scripts\python.exe -m apps.cli publish-drafts --post-id 913736f210d84308b6b7085b822f15ce --yes --login-hold 0 --wait-timeout 600
```

多个草稿可重复传入 `--post-id`：

```powershell
.\.venv\Scripts\python.exe -m apps.cli publish-drafts --post-id POST_ID_1 --post-id POST_ID_2 --yes
```

## GUI 使用

启动 GUI：

```powershell
.\.venv\Scripts\python.exe -m apps.gui
```

进入 `发布草稿` 标签页：

1. 在 `发布日期（北京时间）` 中填写日期，例如 `2026-06-29`。留空会显示全部本地已上传且未发布草稿。
2. 点击 `刷新可发布草稿`，表格会展示标题、上传时间、本地状态、素材数量和 `post_id`。
3. 可在表格中多选具体草稿；如果不选择具体行，则处理当前筛选结果中的全部草稿。
4. 建议先勾选 `只预览，不发布（推荐先运行）` 运行一次，确认平台草稿箱里能匹配到对应标题。
5. 取消 dry-run 后点击 `发布/预览选中的草稿`，GUI 会弹出确认框，确认后才执行发布。

## 实机页面确认

已实际打开小红书创作者中心图文草稿箱和草稿编辑页检查，页面结构如下：

- 草稿箱：位于发布图文页内，包含 `视频笔记`、`图文笔记`、`长文笔记`、`播客笔记` 标签；图文草稿条目显示封面、标题、保存时间，并提供 `编辑`、`删除` 操作。
- 编辑页顶部：图片编辑区、标题、正文、话题、用户/表情按钮、笔记预览/封面预览。
- 编辑页底部固定操作：`暂存离开`、`发布`。
- 内容设置：`加入合集`、`创建合集`、`引用笔记`、`原创声明`、`添加内容类型声明`。
- 添加组件：`添加地点`、`选择群聊`、`标记地点或标记朋友`、`添加路线`、`选择文件`。
- 更多设置：`允许合拍`、`允许正文复制`、`公开可见`、`定时发布`。

当前自动化策略：不主动修改这些发布选项，只打开匹配到的草稿并点击底部 `发布`。如果草稿自身设置不完整或平台弹出确认框，会尝试点击确认发布；如果发布后草稿仍留在草稿箱，会视为验证失败并在终端输出错误。

## 本地状态更新

正式发布成功后，本地 `post.json` 会更新：

- `status` 设为 `published`
- `updated_at` 写入发布时间
- `platform.publish.result` 写入 `published`
- `platform.publish.published_at` 写入本地记录时间
- `platform.publish.source` 写入 `creator_center_draft`

dry-run 不会改动本地状态，也不会点击平台发布按钮。

## 注意事项

- 该功能依赖小红书登录态。无界面发布需要工作区 Chrome Profile 已登录。
- 如果本地显示已上传，但平台草稿箱找不到同标题草稿，命令会报 `draft not found`，不会发布其他不匹配草稿。
- 正式发布前建议先运行 dry-run，因为平台草稿可能被手动删除、改名，或当前 Chrome Profile 与上传时 Profile 不一致。
- `--all` 会选择全部本地已上传且未发布草稿，风险较高，建议优先使用 `--date` 或 `--post-id`。
