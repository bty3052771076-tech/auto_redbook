# 新闻时效性、去重与内容规范任务书

## 1. 背景
用户反馈“每日新闻”草稿缺少发布时间、候选新闻可能重复，以及正文偶发“推测/编造”的风险，需要提升时效性、去重能力与内容严格性。

## 2. 目标
1) 在“每日新闻”草稿正文中明确写出新闻发布时间，提升时效性。
2) 新闻候选列表进行去重，避免重复新闻被选中或影响排序。
3) 严格遵循给定新闻字段生成正文，不得新增事实或细节。

## 3. 非目标
- 不引入新的外部新闻源。
- 不新增复杂的事实核验机制（仅通过提示词与兜底策略约束）。

## 4. 设计与实现
### 4.1 发布时间写入
- 在 `_daily_news_prompt()` 增加硬性要求：新闻内容中必须写出发布时间（使用提供字段，不推测）。
- 新增 `_format_news_seendate()` 与 `_ensure_news_publish_date()`：当正文缺少发布时间时自动补齐。
- 离线兜底正文 `_daily_news_offline_body()` 同样包含“发布时间：YYYY-MM-DD”。

### 4.2 候选新闻去重
- 新增 `_dedupe_candidates()`：按 URL 与标题相似度去重。
- 在 `fetch_daily_news_candidates()` 返回前统一去重，降低重复候选。

### 4.3 内容严格性
- 强化提示词：禁止新增未提供的人名/地点/数字/因果；缺失信息明确写为“未披露/未知”。

## 5. 验收标准
1) 生成“每日新闻”草稿时，正文中出现明确发布时间。
2) 同一批候选新闻中相似标题不重复进入候选或被选中。
3) 正文不出现未提供字段的臆测内容（以提示词与兜底逻辑约束）。

## 6. 测试计划
- 单元测试：
  - `_ensure_news_publish_date()` 能在缺失日期时补齐。
  - `_dedupe_candidates()` 能去除相似标题。
- 手动验证：生成 1 条“每日新闻”草稿，检查发布时间是否出现且格式合理。
