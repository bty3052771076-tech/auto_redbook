# 新闻标题、提示词与 GUI 默认项修复说明（2026-06-20）

## 修复目标

本次修复针对四个问题：

- 每日新闻标题必须是 20 字以内的中文总结标题，不能出现日文假名或 `每日新闻｜` 前缀。
- 候选新闻内容不完整时，先尝试读取原新闻页面摘录，再进行评价；仍不足时不得推测。
- GUI 默认配图来源改为 `aliyun`，优先使用 AI 生图。
- GUI 增加 `登录/检查Profile` 按钮；草稿处理页的时间独立显示为北京时间。

## 每日新闻生成规则

- 标题会经过 `_normalize_daily_news_title(...)` 统一清洗：
  - 去除 `每日新闻｜` 等栏目名前缀。
  - 控制在 20 字以内。
  - 检测并拒绝日文假名，例如 `の`、假名片段等。
  - 如果 LLM 或来源标题不可用，则从摘要、正文片段或关键词生成中文兜底标题。
- 提示词 `_daily_news_prompt(...)` 已强化：
  - 英文、日文或其他语言新闻必须先转写为简体中文。
  - 内容不完整时，必须先查阅原新闻/原文摘录后再评价。
  - 不得推测数字、因果、人物关系或后续结果。
  - URL 仍只保存在本地 metadata，不写进正文。

## 原新闻摘录补全

当 `description + content` 太短或出现 NewsAPI 截断标记时，系统会尝试读取原新闻页面文本，并写入本地元数据与 LLM 输入。

可选环境变量：

```powershell
$env:NEWS_SOURCE_LOOKUP="1"
$env:NEWS_SOURCE_LOOKUP_TIMEOUT_S="8"
$env:NEWS_SOURCE_CONTEXT_MIN_CHARS="120"
```

关闭原文补全：

```powershell
$env:NEWS_SOURCE_LOOKUP="0"
```

## GUI 行为

- 默认配图来源：`aliyun`
- 默认阿里云生图模型：`wan2.7-image`
- 顶部按钮：
  - `打开小红书创作平台`：打开图文发布页。
  - `登录/检查Profile`：打开小红书创作平台主页，用于检查当前工作区 Chrome profile 是否已登录。
- 草稿处理页：
  - 下拉列表只显示标题、状态和 post_id。
  - 时间单独显示在“时间（北京时间）”框中，包括创建、本地更新、上传、执行开始和执行结束时间。
