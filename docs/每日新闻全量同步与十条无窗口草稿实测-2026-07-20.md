# 每日新闻全量同步与十条无窗口草稿实测（2026-07-20）

## 目标

在不显示浏览器窗口的条件下，完成已发布数据全量同步、选题分析，并使用火山引擎有可用额度记录的语言与绘图模型生成 10 条 `每日新闻` 小红书草稿。

## 前置核验

- 已发布数据同步命令：`python -m apps.cli update-metrics --limit 0 --headless --login-hold 0 --wait-timeout 600`。
- 同步完成：页面目标 `398` 条，抓取 `398/398`，缺失 `0`；本地匹配 `323` 条、未匹配 `75` 条。
- 本轮实时额度页面未返回可解析的行：阿里云无窗口登录态失效，火山 Ark 用量页未暴露 `InferenceFreeUsage`。因此没有将“页面不可解析”误判为余额为零。
- 模型选择采用本地最近一次可解析的火山快照（2026-07-04）中的剩余额度记录：`deepseek-v4-pro` 为 500000 token，`doubao-seedream-4-5-251128` 为 199 张图片。该快照仅用于本轮选型，不表示 2026-07-20 的实时余额。

## 数据分析与选题方向

执行 `python -m apps.cli analyze-metrics --save` 后，398 条历史帖中互动表现较好的方向为：

1. 争议文化、体育与品牌：25% 的样本，平均浏览 129.8。
2. 社会民生与公共事件：25% 的样本，平均互动 1.50，出现互动的比例 50%。
3. 国际冲突、外交安全与能源：20% 的样本；适合保持事实性、避免单一情绪化叙述。

后续每日新闻建议按 `3 : 3 : 2 : 1 : 1` 分配为：体育/品牌、社会民生、国际与能源、财经产业、硬科技与健康科学。每条都应优先选择有正文、发布时间和原始链接的来源。

## 实测模型与运行方式

- LLM：火山 Ark `deepseek-v4-pro-260425`。
- 生图：火山 Ark `doubao-seedream-4-5-251128`，竖版 `1440x2560`。
- 执行参数：`--headless --login-hold 0 --wait-timeout 600`。
- 运行过程没有打开可见浏览器窗口。

首次 10 条批量任务在外层一小时限制处失去终端连接，但后台流程仍继续完成。随后对两条未保存草稿使用 `retry` / `run` 定向重试，均通过草稿箱校验，避免重复生成已成功的内容。

## 内容质量处置

初轮复核发现两项不适合保留：

- “麦当娜、BTS 与比伯将献唱世界杯中场”与“世界杯决赛首设中场表演”是同一事件。
- “特朗普指控中国入侵 2020 年大选数”来自转述型节目条目，原始细节不足。

已在小红书草稿箱按精确标题删除两项，并用两条可追溯材料补回：

- “高技术制造业绽放澎湃动能”，来源为人民网－人民日报 2026-07-19 报道，正文包含高技术制造业增加值同比增长 13.3% 等数据。
- “上半年公诉60.3万人”，来源为中国网 2026-07-17 报道，正文包含会议披露的公诉、食品药品安全和安全生产数据。

人工材料存放在 `data/manual_news/`，仅包含公开新闻正文摘要和链接，不含任何 API Key。

## 最终验证

最终保留的 10 条草稿均满足：

- 本地状态 `saved_as_draft`，`uploaded=true`。
- 草稿箱复核步骤返回 `verified_title=True cover_ready=True`。
- 含新闻来源链接与正文。
- 配图来源均为 `volcengine`，模型均为 `doubao-seedream-4-5-251128`。
- 图片生成事件、标题和正文主题在元数据中一一对应；需要评价的稿件采用“客观影响分析”，无视角稿件不强行填充主观评价。

本轮生成过程中曾有一张敏感政治主题图片回退至 Pexels；该草稿已随上述低细节条目删除，因此最终 10 条均为火山 AI 生图。
