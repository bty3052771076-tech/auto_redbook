# 新闻质量闸门与终端/GUI实测（2026-06-20）

## 背景

本次真实链路测试发现，部分 LLM 返回会把用户提示词或提示词中的分类短语当成新闻标题，例如“科技、社会或国际新闻”“科技议题出现进展”。这些标题虽然能上传，但不符合“20 字内、总结新闻事实、不能出现提示词内容”的要求。

## 修复内容

- 标题清洗新增提示词泄漏检测：拒绝“选择一条”“适合小红书”“摘要/正文/点评”等指令文本。
- 标题清洗新增分类片段检测：拒绝直接截取自用户 prompt 的“科技、社会或国际新闻”等分类标题。
- 标题清洗新增泛标题检测：拒绝“科技议题出现进展”“国际议题出现进展”等不可发布标题。
- 英文新闻兜底标题改为优先基于新闻源字段，不再用用户 prompt 里的 `technology` 等分类词覆盖事实。
- 英文新闻增加保守中文映射，例如 sunscreen/FDA -> “防晒审批迎来进展”，NATO/US forces Europe -> “美军欧洲部署审查”。
- 正文兜底同步使用新闻源主题，避免生成“原始来源披露一项科技议题出现新进展”这种过泛正文。
- `image_event` 在英文新闻场景下也会尝试转成中文事件主题，用于更稳定的阿里云生图提示。

## 自动化测试

已新增/扩展回归用例：

- LLM 标题直接回显用户提示词时，最终标题必须来自新闻事实或中文兜底主题。
- LLM 标题为 prompt 分类片段、正文为泛泛“科技议题”时，最终标题和正文必须落到具体新闻主题。
- 英文 NATO/欧洲美军部署新闻不能被用户 prompt 里的 `technology` 误判为科技新闻。
