# 图形界面任务书（模型/参数选择 + 一键执行）

## 背景
当前项目主要通过命令行（`apps.cli`）操作：需要手工拼接参数与环境变量（模型/超时/图片提供商等），对非研发同学不友好，也不利于快速试错与复用常用配置。

## 目标
- 提供一个**简单图形界面（GUI）**，支持：
  - 选择常用功能：`auto`（生成+校验+保存草稿）、`create`（仅生成）、`delete-drafts`（删除草稿）。
  - 选择/输入常用参数：标题、提示词、数量、素材路径、登录等待、超时等。
  - 选择常用模型与配置：LLM 模型、图片生成提供商与模型列表、新闻偏好（中国:海外比例）等。
  - 一键运行并在界面中查看实时日志。
- 提供本地配置落盘（不提交到仓库）：
  - 通过 `.env.gui` 保存/加载 GUI 的环境变量配置，便于复用。

## 非目标
- 不做复杂的“发布管理后台”或账号管理。
- 不做安装包/自动更新等完整分发体系（仅提供一个可快速启动的 exe）。
- 不保证覆盖所有环境变量，仅覆盖常用项；高级参数仍可在命令行使用。

## 方案设计
### 1) 技术选型
- 使用 Python 内置 `tkinter`（无需新增依赖），做一个轻量桌面 GUI。

### 2) 运行方式
- 推荐：激活虚拟环境后运行：
  - `\.venv\Scripts\python -m apps.gui`

### 3) 界面结构（建议）
- Tab1：生成并保存草稿（`auto`）
- Tab2：仅生成（`create`）
- Tab3：删除草稿（`delete-drafts`）
- Tab4：配置（模型/参数/环境变量）

### 4) 执行方式
- GUI 内通过 `subprocess` 调用 `python -m apps.cli ...`，并将 GUI 中设置的环境变量以“子进程环境”方式注入，避免污染当前终端环境。
- 输出日志以流式方式显示在 GUI 文本框中，并支持中止运行。

### 5) 配置落盘
- `.env.gui`：仅用于 GUI 自己读取（仓库已忽略 `.env*`），保存常用环境变量（可含 key，但不建议分享/提交）。

### 6) 打包成 .exe（快速启动）
- 使用 PyInstaller 打包生成 `AutoRedbookGUI.exe`（窗口程序，无控制台）。
- 打包脚本：`scripts/build_gui_exe.ps1`
- 说明：该 exe 作为“快速启动器”，默认需要放在仓库根目录旁边，以便找到 `.venv` 并调用 `apps.cli`。

## 验收标准
- 可打开 GUI 窗口，能够配置参数并成功执行 `auto/create/delete-drafts`。
- GUI 日志区能显示实时输出，并在结束后提示退出码。
- `.env.gui` 的保存/加载可用，且不会被 git 跟踪。

## 测试计划
- 单元测试（不依赖 GUI）：
  - `.env.gui` 解析/保存逻辑。
  - CLI 命令构造函数（参数 → args）。
- 手动验证：
  - 用 GUI 跑一次 `auto --title "每日新闻" --count 1`（可 dry-run），确认流程可用。
