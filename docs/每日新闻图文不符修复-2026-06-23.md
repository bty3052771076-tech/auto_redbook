# 每日新闻图文不符修复（2026-06-23）

## 现象

某些草稿正文是 A 新闻，但配图明显像 B 新闻。例如本次排查到的本地草稿：

- post_id：`7b04e72bec2147e181d3579ba75e688f`
- 草稿标题：`LG显示OLED首获完美色彩亮度认证`
- 正文内容：LG Display OLED 面板获得 “Perfect Color/Brightness” 认证
- 错误字段：`原文标题` 和 `platform.news.image_event` 被写成 `锂提取技术获进展`
- 实际生图 prompt：`生成一张竖版3:4插画，描绘以下事件：锂提取技术获进展。...`

因此图片并不是上传错了，而是生成图片前的 `image_event` 已经和正文不一致。

## 根因

每日新闻由 LLM 返回 `title` / `body` / `topics` / `image_event`。在多候选、多条新闻生成时，LLM 偶尔会把上一条或其它候选的 `原文标题`、`image_event` 串入当前新闻。旧逻辑对这两个字段过度信任：

- 英文源新闻没有中文原题时，会保留 LLM 写入的 `原文标题`。
- `image_event` 只做长度和禁词清理，没有校验它是否和最终标题/正文/picked 新闻源相关。

## 修复

- 新增字段相关性校验：`原文标题` / `image_event` 必须与最终标题、正文或 picked 新闻源有高信号重合。
- 若 `原文标题` 串台，则使用 picked 新闻源推导出的中文标题替换。
- 若 `image_event` 串台，则使用最终标题或 picked 新闻源主题替换。
- 增加 OLED / display / certification 英文标题映射，避免显示面板新闻退化成“国际议题出现进展”。
- 新增回归测试，复现 “LG OLED 正文 + 锂提取 image_event” 的问题。

## 注意

修复只影响新生成的草稿。已经上传到小红书创作者中心的旧草稿不会自动改图，需要删除旧草稿后重新生成。
