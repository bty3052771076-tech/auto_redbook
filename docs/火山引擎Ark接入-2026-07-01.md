# 火山引擎 Ark 接入（2026-07-01）

本次新增火山方舟 / Ark 作为 LLM 和 AI 生图供应商。实现目标是复用现有阿里云的环境变量与 GUI 模型选择逻辑，同时保持密钥只在本机环境变量或 `.env.gui` 中保存，不写入代码、README 或测试。

## 配置

PowerShell 临时配置：

```powershell
$env:LLM_PROVIDER="volcengine"
$env:VOLCENGINE_API_KEY="YOUR_ARK_KEY"
$env:VOLCENGINE_LLM_MODEL="doubao-seed-2-1-turbo-260628"

$env:IMAGE_PROVIDER="volcengine"
$env:VOLCENGINE_IMAGE_MODEL="doubao-seedream-5-0-lite-260128"
$env:VOLCENGINE_IMAGE_SIZE="1440x2560"
```

也可以在 GUI 的 `配置` 页填写：

- `VOLCENGINE_API_KEY`
- `VOLCENGINE_LLM_BASE_URL`
- `VOLCENGINE_IMAGE_SIZE`

GUI 的供应商下拉框已新增：

- LLM：`volcengine`
- 图片来源：`volcengine`

## 免费额度查询

本次新增 `volcengine-quota` CLI 和 GUI 配置页入口，用于读取官方 Ark 控制台页面，不调用模型推理 API：

```powershell
.\.venv\Scripts\python.exe -m apps.cli volcengine-quota --model doubao-seed-2-1-turbo-260628 --model doubao-seedream-5-0-lite-260128 --login-hold 600 --wait-timeout 120
```

首次使用需要在可视浏览器里登录火山引擎控制台。登录态保存在当前工作区：

```text
data/browser/volcengine-console-profile
```

后续已登录后可以加 `--headless --login-hold 0`。字段解析和双供应商说明见 `docs/模型免费额度查询-2026-07-01.md`。

## 当前 API 证据（2026-07-01 13:34 更新）

官方文档显示 Ark 兼容 OpenAI SDK，文本对话使用：

```text
https://ark.cn-beijing.volces.com/api/v3/chat/completions
```

```text
https://ark.cn-beijing.volces.com/api/v3/images/generations
```

图片生成：

- `doubao-seedream-5-0-lite-260128`

## 当前账号状态

本次重新实测显示：当前 API Key 已可真实调用指定 LLM 和 Seedream 图片模型。

- `doubao-seed-2-1-turbo-260628`：`POST /api/v3/chat/completions` 返回 `200`，短回复烟测成功。
- `doubao-seedream-5-0-lite-260128`：`POST /api/v3/images/generations` 成功返回图片 URL，并落盘到 `output/volcengine_smoke/ai_volcengine_20260701_052331.jpg`。
- `doubao-seedream-5-0-lite-260128` 与 `doubao-seedream-5-0-260128` 的空 prompt 探针都先通过模型鉴权，再返回 `prompt cannot be empty`，说明模型入口可达。
- `doubao-seedream-5-0-lite-260128` 使用 `1024x1024` 会返回尺寸错误：图片像素数必须至少为 `3686400`。项目默认尺寸已改为 `1440x2560`。

注意：烟测图片的提示词包含“报纸元素”，实际生成图里出现了明显的问号/类文字块。API 可用，但生产提示词仍应继续避免“报纸、海报、标题、文字载体”等容易诱发文字的描述。
