# 模型免费额度查询设计（2026-07-01）

> 2026-07-03 更新：当前实现已增强中文数量单位、表头顺序、`status` 状态和 `--save-raw` 本地快照。最新说明见 `docs/模型免费额度查询-2026-07-03.md`。本文保留为早期设计记录。

## 背景

本项目现在支持阿里云百炼 / DashScope 与火山引擎方舟 / Ark 两组 LLM 和生图供应商。生成“每日新闻”前，需要知道指定模型是否还有免费额度、免费额度是否过期，以及后续真实生成会不会因为余额不足中断。

本次采用的方式是读取官方控制台页面，而不是调用模型 API 探测余额。这样可以避免为了查额度而消耗 token 或图片生成次数。

官方依据：

- 阿里云百炼免费额度说明：<https://help.aliyun.com/zh/model-studio/new-free-quota>
- 阿里云模型调用统计说明：<https://help.aliyun.com/zh/model-studio/model-usage-statistics>
- 火山引擎 Ark 免费推理额度说明：<https://www.volcengine.com/docs/82379/1399514>
- 火山引擎 Ark 模型列表说明：<https://www.volcengine.com/docs/82379/1330310>

## 查询方式

### 阿里云百炼

CLI：

```powershell
.\.venv\Scripts\python.exe -m apps.cli aliyun-quota --model glm-5.2 --model qwen-image-2.0-pro-2026-04-22 --login-hold 600 --wait-timeout 120
```

登录态保存位置：

```text
data/browser/aliyun-console-profile
```

工作方式：

- 打开官方百炼免费额度页。
- 用 Playwright 读取页面可见表格/文本。
- 按模型名解析 `remaining / used / total / unit / expires_at`。
- 输出结果到 CLI 或 GUI 日志。

### 火山引擎 Ark

CLI：

```powershell
.\.venv\Scripts\python.exe -m apps.cli volcengine-quota --model doubao-seed-2-1-turbo-260628 --model doubao-seedream-5-0-lite-260128 --login-hold 600 --wait-timeout 120
```

登录态保存位置：

```text
data/browser/volcengine-console-profile
```

工作方式：

- 打开官方 Ark 用量/额度相关控制台页面。
- 用 Playwright 读取页面可见表格/文本。
- 按模型名解析 `remaining / used / total / unit / expires_at`。
- 输出结果到 CLI 或 GUI 日志。

## GUI 入口

打开 GUI：

```powershell
.\.venv\Scripts\python.exe -m apps.gui
```

进入 `配置` 页签，使用：

- `查询阿里云百炼额度`
- `查询火山引擎 Ark 额度`

首次登录建议：

- 不勾选 Headless。
- `Login hold (s)` 设为 `600`。
- 在弹出的浏览器里完成供应商控制台登录。

后续如果 profile 已登录，可以勾选 Headless 并把登录等待设为 `0`。

## 实现文件

- `src/aliyun/quota.py`：阿里云百炼额度候选模型、页面读取、解析和格式化。
- `src/volcengine/quota.py`：火山引擎 Ark 额度候选模型、页面读取、解析和格式化。
- `apps/cli.py`：新增 `volcengine-quota`，保留 `aliyun-quota`。
- `apps/gui.py`：配置页新增火山引擎 Ark 额度查询按钮；GUI 不再暴露“仅生成”页签。

## 解析限制

- 供应商控制台页面是登录态页面，首次必须人工登录。
- 控制台 UI 文案或表格结构变化时，解析字段可能显示 `unknown`。
- 输出 `unknown` 时，程序仍会保留可见文本用于排查；最终额度以官方控制台显示为准。
- 查询额度不会调用模型推理 API；真实生成“每日新闻”仍会实际消耗对应 LLM 和生图模型额度。
