# 每日新闻中文来源扩展与筛选诊断（2026-07-11）

## 问题

当提示词为“世界杯”时，自动流程可能返回 `0 within 14 days`。这不等于互联网上没有相关新闻：无 Key 的原有链路主要使用国际 Google RSS、BBC RSS 和热榜；热榜记录经常没有标准发布时间，后续三天/七天/十四天窗口会将其过滤。若国际源对中文提示词召回不足，最终候选数就会变成 0。

## 修改

自动新闻源计划新增独立的中文区域 Google News RSS：

- `google_rss_cn`：`hl=zh-CN`、`gl=CN`、`ceid=CN:zh`，不需要 API Key，并保留 RSS 发布时间。
- `google_rss`：继续作为国际来源。
- `bbc_rss`：继续作为国际媒体补充。
- `hotnews`：仍作为热度补充，但无日期的记录不能绕过日期窗口。

自动模式的顺序调整为：已配置的 NewsAPI/GNews/聚合数据 -> 中文 Google RSS -> 国际 Google RSS -> BBC -> 热榜。来源健康记录会分别保存 `item_count`、`dated_count`、`url_count` 和状态，便于区分“来源为空”“没有日期”“日期筛选后不足”。

## 验证

回归测试覆盖中文 Google RSS 的区域参数和自动计划来源。真实运行时可执行：

```powershell
.\.venv\Scripts\python.exe -m apps.cli auto --title "每日新闻" --prompt "世界杯 体育 足球" --count 1 --assets-glob "assets/empty/*" --login-hold 0 --wait-timeout 600
```

若仍不足，查看 `data/source_health/daily_news.json`：`google_rss_cn` 的 `item_count` 表示 RSS 返回数，`dated_count` 表示含可解析发布时间的数量；如果两者都是 0，则是网络/RSS 服务不可达或该时段确实没有召回，不能归因于 LLM。

本次没有写入任何 API Key。
