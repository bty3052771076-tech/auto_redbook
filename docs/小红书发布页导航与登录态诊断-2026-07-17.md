## 根因诊断

第一次失败表现为发布页 `Page.goto` 等待 `domcontentloaded` 超时 600 秒。增加诊断后确认：

1. 发布页导航曾返回 `ERR_NETWORK_ACCESS_DENIED`。
2. 获得网络访问授权后，发布页可以提交导航，但页面被重定向到 `/login?redirectReason=401`。
3. 当前 `data/browser/chrome-profile` 的 Default Profile 已失效登录；旧的 `Default1` Profile 也进入登录页，仅有匿名 Cookie。
4. 页面 HTML 只有空的 `#app`，没有编辑器和文件上传控件，因此不是图片、正文或选择器问题。

无窗口模式不能完成短信、扫码或验证码登录，不能绕过小红书登录验证。
