# 新闻自动化修复与实测报告

日期：2026-06-19
范围：每日新闻生成、AI 生图、小红书图文草稿保存、草稿箱标题核验。

## 修复内容

- 每日新闻正文不再把用户提示词写入正文或 topics；离线安全正文也不再拼接原始 prompt。
- `NEWS_PROVIDER=auto` 在 NewsAPI 不可用时会继续尝试 GDELT，并记录 `provider_attempts` / `provider_errors`。
- 新增 `NEWS_PROVIDER=file` 与 `NEWS_CANDIDATES_FILE`，可使用人工核验过的新闻候选 JSON 作为真实新闻源。
- 新闻源全部失败时不再降级为“普通生成 1 条每日新闻”，而是失败退出，避免编造新闻。
- 小红书标题/正文填充改为优先使用真实键盘输入，并在保存前等待前端状态沉淀。
- 草稿保存后必须进入草稿箱并按具体标题核验，不能再把“保存成功 toast”当作最终成功。
