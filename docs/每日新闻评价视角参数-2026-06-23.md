# 每日新闻评价视角参数说明（2026-06-23）

## 背景

每日新闻草稿的 `评价` 段需要支持不同分析角度，但旧提示词中存在硬编码立场，无法在 GUI 或 CLI 中显式控制。现在新增 `评价视角` 参数，默认值为 `无视角评价`。

## 行为

- CLI 新增 `--evaluation-viewpoint`，适用于 `create` 和 `auto`。
- GUI 的 `自动发帖` 与 `仅生成` 页签都新增 `评价视角` 输入框。
- 默认 `无视角评价` 不预设国家、行业、投资者或平台立场，只要求基于已给事实和原文摘录客观分析。
- 自定义视角会写入每日新闻 LLM 提示词，但仍必须保持事实约束；信息不足时 `评价` 可以为空。
- 每条每日新闻草稿会在 `post.json` 的 `platform.news.evaluation_viewpoint` 中保存本次使用的视角。

## 示例

```powershell
.\.venv\Scripts\python.exe -m apps.cli auto --title "每日新闻" --prompt "科技热点" --evaluation-viewpoint "产业政策视角" --assets-glob "assets/empty/*" --count 2 --login-hold 600 --wait-timeout 600 --force
```

如果不需要指定角度，可以省略参数，系统会使用：

```text
无视角评价
```
