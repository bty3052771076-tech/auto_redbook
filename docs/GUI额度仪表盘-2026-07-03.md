# GUI 额度仪表盘（2026-07-03）

## 背景

“自动发帖”页原先右侧下方主要显示草稿预览。随着 Aliyun / Volcengine 模型额度查询功能加入，生成前更需要快速判断当前 LLM 和生图模型是否还有可用免费额度。

本次改造目标：

- 在“自动发帖”页右侧下方显示各平台模型额度。
- 用横条呈现剩余额度比例；不可计算比例时明确显示状态。
- 增加“同步免费额度”按钮，直接从 GUI 触发两个平台额度同步。
- 保留其他页面的记录详情/草稿预览能力，避免影响草稿处理、发布草稿、已发布数据分析流程。

## 设计

视觉方向采用“运行控制台右侧的额度仪表”：

- 阿里云和火山引擎按平台分组。
- LLM / image 模型按类型排序。
- 有 `remaining / total` 时显示横向剩余条。
- 没有可计算数字时使用虚线条并显示状态，例如：
  - `网页未展示`
  - `平台未返回`
  - `未找到`
  - `无免费额度`
  - `已用完`

右侧下方面板现在按当前左侧 Notebook 页切换：

- `自动发帖`：显示 `模型额度` 仪表盘。
- 其他页面：显示 `记录详情`，保留原来的草稿/已发布数据预览入口。

## 同步逻辑

新增 CLI：

```powershell
.\.venv\Scripts\python.exe -m apps.cli sync-quotas --headless --login-hold 0 --wait-timeout 120
```

GUI 的“同步免费额度”按钮会调用该命令，并默认同步：

Aliyun：

- `glm-5.2`
- `qwen-image-2.0-pro-2026-06-22`

Volcengine：

- `glm-5.2`
- `deepseek-v4-pro`
- `deepseek-v4-flash`
- `doubao-seedream-5-0-lite-260128`

同步命令会分别保存：

```text
data/quota/aliyun_quota_YYYYmmdd_HHMMSS.json
data/quota/volcengine_quota_YYYYmmdd_HHMMSS.json
```

即使某个平台返回登录/网页未展示/额度未返回等错误，`sync-quotas` 仍会保存可获取的快照并以 `warnings` 输出，方便 GUI 刷新另一平台的可用数据。

## 2026-07-03 夜间修复：真实额度解析

问题现象：

- Aliyun 在 GUI 中默认以 headless 方式同步，控制台登录态不可用时只能得到 `Aliyun console login required`。
- Volcengine 已经返回了模型元数据，但 GUI 仍显示 `平台未返回`。

根因：

- Aliyun 需要可见浏览器完成登录/风控后才能读取百炼控制台；GUI 同步按钮默认 headless 不适合首次同步。
- Volcengine 的实际免费额度不只在旧字段 `InferenceFreeUsage` 中，当前目标模型返回的是 `ResourcePackItems`，其中 `Type=FreeInference`、`Total`、`Consumed` 才是真正的免费额度。
- Volcengine 页面有时不会主动触发 charge-item 请求，导致没有 `x-csrf-token`；现在会从任意 Ark 控制台 API 请求中捕获 CSRF，再主动查询目标模型。

修复：

- GUI 的“同步免费额度”默认改为可见浏览器，便于 Aliyun 首次登录。
- Aliyun 新增控制台 JSON `freeTierQuotas` 解析，页面文本无法覆盖当前分页时仍能拿到目标模型额度。
- Aliyun 状态判断改为优先信任数值，避免“免费额度即将用尽TOP3模型”把 `remaining > 0` 的模型误判为 `exhausted`。
- Volcengine 新增 `ResourcePackItems` / `FreeInference` 解析。
- Volcengine 主动查询在没有 charge-item 请求头时会尝试默认 headers；如果页面已有其他 Ark API 请求，则复用捕获到的 CSRF。

## 2026-07-04 补充：全量同步与点击切换

当前 GUI 右下角额度面板不再只同步固定的 2 个 Aliyun 模型和 4 个 Volcengine 模型。`同步免费额度` 默认调用：

```powershell
.\.venv\Scripts\python.exe -m apps.cli sync-quotas --all-free --login-hold 600 --wait-timeout 120
```

如需旧行为，可用 `--target-only` 加 `--aliyun-model` / `--volcengine-model`。

新增交互：

- 模型名显示为按钮式文本。
- `available` 且 `remaining > 0` 的 LLM 行可点击，点击后切换左侧 `LLM 供应商` 和 `LLM 模型`。
- `available` 且 `remaining > 0` 的 image 行可点击，点击后切换左侧 `图片来源` 和 `生图模型`。
- `unknown`、`exhausted`、`not_found`、`quota_not_returned` 等行仅展示，不会切换生成模型。
- 如果最新快照为空失败快照，GUI 会跳过并回退到上一份有效快照。
