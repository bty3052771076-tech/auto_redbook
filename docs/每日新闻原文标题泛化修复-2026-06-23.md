# 每日新闻原文标题泛化修复（2026-06-23）

## 现象

部分每日新闻草稿的正文 `原文标题` 会变成：

- `科技议题出现进展`
- `国际议题出现进展`
- `平台封锁VPN用户`

这些标题和正文事实不完全对应，容易让草稿看起来像串稿。

## 原因

问题不是小红书平台改写，而是本地后处理兜底逻辑导致的：

- 代码为了防止 LLM 串候选新闻，会校验 `原文标题` 是否和当前候选新闻匹配。
- 当新闻源标题是英文、日文或其他非中文标题时，原本的 `原文标题` 兜底会调用草稿短标题压缩逻辑。
- 草稿短标题压缩逻辑里有 `科技议题出现进展`、`国际议题出现进展`、`平台封锁VPN用户` 等兜底模板。
- 这些模板适合极端失败时的短标题兜底，但不适合作为正文里的 `原文标题`。

## 修复

- `原文标题` 不再直接使用泛化兜底标题。
- 来源标题是中文时，仍优先保留来源原题。
- 来源标题不是中文、且 LLM 返回的 `原文标题` 是泛化或错配标题时，优先使用已经规范化的中文草稿标题。
- 如果没有可靠中文标题，最后才保留清洗后的原始外文标题，避免凭空生成无关中文标题。
- 每日新闻提示词新增约束：`原文标题` 不得写“某某议题出现进展/受关注/出现变化”等概括兜底标题。

## 影响

新生成的草稿会修复该问题。已经上传到小红书草稿箱或已经落盘的旧草稿不会自动改写，需要删除后重新生成。
