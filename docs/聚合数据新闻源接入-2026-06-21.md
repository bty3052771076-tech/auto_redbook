# 聚合数据新闻源接入

日期：2026-06-21

## 背景

此前“每日新闻”在线来源主要依赖 NewsAPI / GNews，GDELT 已因低质量摘录和正文噪声从生产链路移除。为提升国内新闻可用性，本次新增聚合数据 Juhe：

- 新闻头条：适合国内、国际、社会、科技、体育、娱乐等分类新闻。
- 财经新闻：适合财经、经济、公司、市场相关 query。

真实 APP-key 不写入代码、README、测试或提交记录。推荐使用环境变量；如需本机文件，可复制 `docs/juhe_api-key.example.md` 为 `docs/juhe_api-key.md`，该文件已被 `.gitignore` 忽略。

## 配置

PowerShell：

```powershell
$env:NEWS_PROVIDER="juhe"
$env:JUHE_NEWS_APPKEY="YOUR_JUHE_NEWS_APPKEY"
$env:JUHE_FINANCE_NEWS_APPKEY="YOUR_JUHE_FINANCE_NEWS_APPKEY"
```

自动模式：

```powershell
Remove-Item Env:NEWS_PROVIDER -ErrorAction SilentlyContinue
$env:JUHE_NEWS_APPKEY="YOUR_JUHE_NEWS_APPKEY"
$env:JUHE_FINANCE_NEWS_APPKEY="YOUR_JUHE_FINANCE_NEWS_APPKEY"
```

当 `NEWS_PROVIDER=auto` 且未设置 `NEWS_CANDIDATES_FILE` 时，当前顺序为：

1. NewsAPI：检测到 `NEWS_API_KEY` / `NEWSAPI_API_KEY` 时启用。
2. GNews：检测到 `GNEWS_API_KEY` / `GNEWS_TOKEN` 时启用。
3. Juhe：检测到 `JUHE_NEWS_APPKEY` 或 `JUHE_FINANCE_NEWS_APPKEY` 时启用。
4. hotnews：上述 Keyed API 未配置或调用失败时，最后使用无需 Key 的 hot_news 热榜候选源。

## 行为说明

- `NEWS_PROVIDER=juhe` 会统一返回项目内部 `NewsItem`，后续继续复用标题总结、正文质量闸门、URL 历史查重、AI 配图、上传草稿链路。
- 新闻头条接口会根据 query 映射分类：`technology/science/科技` -> `keji`，`world/international/国际` -> `guoji`，`society/health/社会/民生` -> `shehui`，`china/国内` -> `guonei`。
- 财经相关 query 会优先走财经新闻接口：`财经`、`business`、`economy`、`finance`、`market`、`stock` 等。
- 新闻头条默认开启详情拉取：`JUHE_NEWS_FETCH_DETAIL=1`。代码会用 `uniquekey` 请求详情正文，默认最多对前 10 条候选拉详情，可用 `JUHE_NEWS_DETAIL_LIMIT` 调整。
- Juhe 是分类接口，不是全文关键词搜索接口，因此不会用英文关键词相关性过滤结果，避免“财经新闻标题不含 business 被误杀”的问题。

## 错误与安全

- Juhe 网络错误会显示为 `Juhe HTTP error ...`、`Juhe request failed ...`、`Juhe request timed out` 等脱敏信息。
- 代码不会把请求 URL 中的 `key` 拼进异常信息。
- 测试覆盖了错误信息不泄露 APP-key。

## 验证

已新增单元测试：

- 新闻头条列表能映射标题、来源、发布时间、图片、链接，并用详情接口补正文。
- 财经 query 会优先调用财经新闻接口。
- 自动模式在 NewsAPI/GNews key 不存在时能发现 Juhe。
- Juhe 出错时异常信息不包含 APP-key。

执行命令：

```powershell
.\.venv\Scripts\python.exe -m pytest tests\test_daily_news.py -k juhe -q
```

当前结果：`4 passed`。
