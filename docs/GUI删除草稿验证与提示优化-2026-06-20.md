# GUI删除草稿验证与提示优化（2026-06-20）

## 背景

旧版 GUI 删除页使用两个复选框：

- `dry-run 只预览`
- `--yes 跳过确认`

这两个字段是 CLI 参数名，放在 GUI 中容易让人误解；部分环境里复选框状态还会显示成类似 `❌` 的符号，不适合删除这种高风险操作。

## 界面调整

删除页已改为两个明确的下拉选项：

- 删除模式
  - `安全预览（不删除）`
  - `正式删除（会删除小红书草稿）`
- 确认方式
  - `执行前确认（推荐）`
  - `自动确认（不再弹出确认）`

同时增加动态提示：

- 安全预览：只列出将被删除的草稿，不删除任何平台草稿。
- 正式删除 + 自动确认：点击后会直接删除匹配的小红书草稿，请先确认 `limit` 和 `--all`。
- 正式删除 + 执行前确认：命令行会再次询问确认。

预览模式下即使选择了“自动确认”，GUI 也不会传递自动确认参数，避免语义混乱。

## 如何在GUI中删除所有平台草稿

如果确实要删除小红书创作平台里的所有草稿：

1. 进入 `删除草稿` 页。
2. 勾选 `--all 所有类型`。
3. `草稿位置` 选择 `publish`。
4. `limit (0=不限)` 填 `0`。
5. `删除模式` 先选择 `安全预览（不删除）` 并运行一次。
6. 确认数量无误后，将 `删除模式` 改为 `正式删除（会删除小红书草稿）`。
7. `确认方式` 建议选择 `执行前确认（推荐）`；如果确认无误并希望自动执行，可选择 `自动确认（不再弹出确认）`。
8. 点击 `运行 delete-drafts`。

注意：该功能删除的是小红书创作平台草稿箱中的草稿，不会删除本地 `data/posts` 新闻草稿记录。

通过 GUI 删除页按钮触发：

```text

```

结果：

- 图文草稿：`11`
- 视频草稿：`0`
- 文章草稿：`0`

### GUI真实删除

通过 GUI 删除页按钮触发受控删除：

```text
delete-drafts --all --limit 1 --yes --login-hold 0 --wait-timeout 360
```

结果：

- 删除图文草稿：`1/11`
- 删除视频草稿：`0/0`
- 删除文章草稿：`0/0`
- 退出码：`0`

随后再次预览：

- 图文草稿：从 `11` 降到 `10`
- 视频草稿：`0`
- 文章草稿：`0`

本地记录核验：
