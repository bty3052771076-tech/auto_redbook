# GUI 运行选项布局修复（2026-06-20）

## 问题

自动发帖页原先把 `dry-run`、`无界面上传`、`login-hold`、`wait-timeout` 全部放在同一条横向布局中。窗口宽度或左侧工作区变窄时，`wait-timeout` 一侧容易被挤压或截断。

## 修复

- 将自动发帖页改为可滚动内容区，避免内容高度超过窗口时控件不可达。
- 将“运行选项”上移到标题、提示词等表单之前，保证高频参数优先可见。
- 将运行选项改为面板式布局：
  - 左侧为 `dry-run`、`无界面上传`、`force` 三个开关。
  - 右侧为 `登录等待（秒）` 和 `页面等待（秒）` 两个输入框。
- 将标题快捷按钮下移到独立一行，避免和标题输入框抢宽度。
- 将“没有本地图片时会按配图来源自动补图”提示下移到独立一行，避免右侧截断。

## 验证

- `python -m py_compile apps/gui.py` 通过。
- `pytest tests/test_gui.py -q` 通过。
- 启动 GUI 后使用窗口句柄截图验证：运行选项、等待时间输入框、标题快捷按钮均完整显示。
- 验证截图仅保存在系统临时目录，验证完成后已删除，没有保留到仓库。
