# 每日新闻点评与正文通顺优化

## 背景

每日新闻草稿中仍可能出现空泛点评，例如：

```text
这类新闻适合先看事实，再看影响。已经公开的信息可以作为判断起点，但不宜把尚未确认的后续结果提前写成结论。接下来可以重点关注权威更新、执行细节和各方反馈。
```

这类句子虽然谨慎，但不是真正基于新闻事实的评价；对读者也没有提供额外判断价值。

## 修复原则

- 点评不再强制输出。事实不足、影响不可核验时，直接省略整个“点评：”区块。
- 如果输出点评，必须回扣新闻主体、受影响对象和可核验影响边界，保持客观公正。
- 禁止把“先看事实、再看影响”“关注权威更新”等方法论模板当作点评。
- 正文必须通顺，清理网页导航、栏目名、JSON 片段、提示词回显等噪声。

## 代码改动

- `src/workflow/create_post.py`
  - `_daily_news_prompt(...)`：改为“点评为可选”，增加“没有可核验影响时省略点评”和禁止空泛点评的提示词约束。
  - `_daily_news_comment_is_generic(...)`：新增空泛点评识别。
  - `_remove_generic_daily_news_comment(...)`：当 LLM 输出已知模板点评时，从正文中移除该点评区块。
  - `_daily_news_fact_based_comment(...)`：仅在气象防灾、AI、体育、人道主义、经贸等已有事实能支撑时生成具体点评。
  - `_ensure_daily_news_sections(...)`：不再为单段正文自动硬补点评。
  - `_daily_news_offline_body(...)`：信息稀疏兜底不再附带模板点评。

## 回归测试

新增或调整测试：

- 单段正文只补“要点摘要 / 新闻内容”，不再自动发明点评。
- 已知空泛点评模板会被删除。
- 提示词必须包含“点评为可选”“没有可核验影响时省略点评”等约束。
- 有事实支撑的气象防灾新闻会生成具体点评。
