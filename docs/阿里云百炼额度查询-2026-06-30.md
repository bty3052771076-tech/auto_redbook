# 阿里云百炼额度查询（2026-06-30）

## 背景

本项目默认使用阿里云百炼 / DashScope 作为 LLM 和 AI 生图供应商，因此需要在生成新闻前确认免费额度、到期时间和模型是否仍可用。

根据阿里云官方文档，百炼免费额度主要在控制台“免费额度”页面查看；模型用量统计页面也可查看调用量，但通常不是实时余额。本项目没有伪造一个 DashScope API Key 余额接口，而是新增了一个浏览器自动读取官方控制台页面的功能，避免为了探测额度而调用模型、消耗额度。

官方入口：

- 免费额度说明：<https://help.aliyun.com/zh/model-studio/new-free-quota>
- 模型调用统计：<https://help.aliyun.com/zh/model-studio/model-usage-statistics>
- 百炼免费额度页：<https://bailian.console.aliyun.com/cn-beijing/?tab=costing-balance>

## CLI 用法

首次使用建议可视化打开并登录阿里云控制台：

```powershell
.\.venv\Scripts\python.exe -m apps.cli aliyun-quota --model qwen3.7-plus --model wan2.7-image --login-hold 600 --wait-timeout 120
```

登录态会保存在工作区内：

```text
data/browser/aliyun-console-profile
```

确认该 profile 已登录后，可以无界面查询：

```powershell
.\.venv\Scripts\python.exe -m apps.cli aliyun-quota --model qwen3.7-plus --model wan2.7-image --headless --login-hold 0 --wait-timeout 120
```

不传 `--model` 时，程序会默认筛选当前配置中的阿里云 LLM 模型和阿里云生图模型，包括 `ALIYUN_LLM_MODELS`、`ALIYUN_LLM_MODEL`、`ALIYUN_IMAGE_MODELS`、`ALIYUN_IMAGE_MODEL`。

只想打开官方页面，不解析结果：

```powershell
.\.venv\Scripts\python.exe -m apps.cli aliyun-quota --open-only
```

## GUI 用法

打开 GUI：

```powershell
.\AutoRedbookGUI-Launcher.exe
```

进入 `配置` 页签，找到 `阿里云百炼额度查询` 区域：

- `模型筛选`：逗号、空格或分号分隔模型名，例如 `qwen3.7-plus,wan2.7-image,wan2.7-image-pro`
- `无界面查询`：仅在 `data/browser/aliyun-console-profile` 已登录阿里云时勾选
- `登录等待（秒）`：首次登录建议 `600`
- `页面等待（秒）`：等待免费额度页加载，默认 `120`

点击 `查询阿里云百炼额度` 后，结果会显示在 GUI 右侧运行日志中。

## 输出字段

CLI/GUI 输出表格字段：

- `model`：模型名
- `kind`：`llm` / `image` / `unknown`
- `remaining`：解析到的剩余额度
- `used`：解析到的已用额度
- `total`：解析到的总额度或免费额度
- `unit`：`Token`、`张`、`次` 等单位
- `expires_at`：解析到的到期日期

如果某个字段显示 `unknown`，表示控制台可见文本里没有稳定可解析的数字。此时请手动打开百炼免费额度页确认，或展开控制台表格后重试。

## 限制

- 这是官方控制台读取功能，不是 DashScope API Key 余额接口。
- 首次使用需要在可视浏览器中登录阿里云控制台。
- 若阿里云控制台 UI/表格文案变化，解析器可能只能输出 `unknown`，但仍会保留可见原始行文本用于排查。
- 用量统计页面可能存在延迟，实际免费额度和到期时间以阿里云控制台显示为准。
