# 中国/海外新闻比例任务书（每日新闻 6:4）

## 1. 背景
用户希望“每日新闻”整体更偏向中国新闻，同时保留一定比例的海外新闻，目标比例约为中国:海外 = 6:4。

## 2. 目标
1) 当生成多条“每日新闻”（`--count > 1`）时，按比例优先选择中国新闻，同时保留海外新闻。
2) 当生成单条“每日新闻”（`--count = 1`）时，也应适度倾向中国新闻（在不明显降低相关性的前提下）。
3) 保持可配置：允许通过环境变量调整比例与偏好强度。

## 3. 非目标
- 不引入新的新闻源，不做事实核验。
- 不保证每次严格精确 6:4（当候选不足时会用另一侧补齐）。

## 4. 设计与实现
### 4.1 中国新闻判定
优先使用结构化字段：
- `sourcecountry` 为 China/CN/CHN 等。
- 其次使用域名后缀：`.cn/.gov.cn/.edu.cn`。

### 4.2 比例策略
- 默认 `NEWS_CHINA_RATIO=0.6`。
- 对候选列表先按现有相关性/多源一致性排序，再在最终选取阶段做“按比例取数 + 不足补齐”。

### 4.3 轻度倾向
- 默认 `NEWS_CHINA_BONUS=0.15`，对中国新闻在相关性排序上做轻微加分（可调）。

## 5. 验收标准
- `--count 5` 时，默认能选出约 3 条中国新闻 + 2 条海外新闻（候选足够时）。
- `--count 1` 时，若候选中存在中国新闻，倾向选中中国新闻。
- 可通过 `NEWS_CHINA_RATIO` 调整比例。

## 6. 测试计划
- 单测：构造 `.cn` 与 `.com` URL 的候选列表，断言 `count=5` 时中国新闻条数为 3。
